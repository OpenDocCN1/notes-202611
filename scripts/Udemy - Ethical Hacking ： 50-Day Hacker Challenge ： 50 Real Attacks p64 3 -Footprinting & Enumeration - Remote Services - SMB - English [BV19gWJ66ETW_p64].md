

🛡️ 道德黑客：50天黑客挑战：03：远程服务 - SMB 足迹分析与枚举

在本节课中，我们将学习如何针对 SMB 远程服务进行足迹分析与枚举。SMB 是一种在 Windows 网络中非常常见的协议，主要用于文件共享、网络浏览和打印服务。如果管理员配置不当，比如开启了匿名访问，攻击者就有机会浏览共享文件夹，下载敏感文件，甚至通过上传恶意文件获得对服务器的完全控制权。我们会一起完成从搜索存活目标、探测操作系统、查找匿名访问、枚举共享目录，到下载敏感文件的完整实战流程。


在开始实操之前，我们先搞清楚 SMB 协议到底是什么。SMB 全称是服务器消息块协议，英文叫 Server Message Block。它是一种网络协议，主要应用于 Windows 网络环境，允许不同计算机之间进行文件共享、网络浏览、打印服务，以及网络中其他进程间的通信。在渗透测试场景中，SMB 的默认端口是 445，这是我们后续所有操作的关键入口。


```text
SMB = 服务器消息块协议（Server Message Block）
主要用途：Windows 网络中的文件共享、网络浏览、打印服务及进程间通信
默认端口：445
```


了解了协议的基本作用，接下来我们看看攻击者通常会盯着哪些攻击面。围绕 SMB 的攻击面主要集中在错误配置上，最常见的情况就是管理员不小心开启了匿名访问。一旦匿名访问被启用，攻击者就可以使用一些专门的工具去访问这些服务，进而枚举与远程服务相关的权限。此外，一些不必要的管理共享，比如 admin$ 和 IPC$，也经常成为攻击者的目标。


以下是 SMB 中常见的容易被错误配置的服务示例：

![](img/bab6e912e8ca6537a92e01c2bd911558_1.png)

![](img/bab6e912e8ca6537a92e01c2bd911558_2.png)

- admin$：系统管理共享，通常用于远程管理，若开启匿名访问风险很高。
- IPC$：进程间通信共享，攻击者可以通过它枚举系统信息或尝试登录。


![](img/bab6e912e8ca6537a92e01c2bd911558_4.png)

![](img/bab6e912e8ca6537a92e01c2bd911558_5.png)

理论部分讲完了，接下来进入实战环节。我们要做的第一件事，就是在互联网上找到开放了 SMB 服务的存活目标主机。为此，我们可以使用专门面向渗透测试人员的在线搜索引擎，比如 Fofa、Shodan、Censys 这类工具。在这些搜索引擎中，你可以输入特定的查询语句，筛选出运行 SMB 协议的设备。


![](img/bab6e912e8ca6537a92e01c2bd911558_7.png)

针对 SMB 服务的搜索查询示例如下：

![](img/bab6e912e8ca6537a92e01c2bd911558_9.png)

```
protocol="SMB" and banner="Tesla"
```

![](img/bab6e912e8ca6537a92e01c2bd911558_11.png)

![](img/bab6e912e8ca6537a92e01c2bd911558_12.png)

这条查询语句的意思是，寻找协议为 SMB 且服务标识包含 Tesla 的目标。你也可以把 Tesla 替换成 WordPress 或其他你感兴趣的特定目标，这就是你需要下达给搜索工具的指令方式。


执行搜索之后，你可能会得到接近 40 个结果，这些目标分布在俄罗斯、墨西哥、巴西、中国等不同地区。拿到这些结果之后，你需要把它们导出到一个文本文件中。除了手动复制粘贴，大多数搜索引擎也支持直接下载导出文件，这样更方便一些。导出的文件通常包含 IP 地址、端口、协议等信息。我们需要做的就是把其中的 IP 地址复制出来，去除重复项，然后保存为一个名为 SMB_IP.txt 的文本文件。这样一来，第一步从搜索引擎收集存活目标的工作就完成了。


![](img/bab6e912e8ca6537a92e01c2bd911558_14.png)

拿到目标 IP 列表之后，不能立刻发起攻击，我们需要先了解目标运行的是什么操作系统。这就是足迹分析阶段要做的事情。在这一步，我们将使用一个名为 nuclei 的工具，配合 Nmap 脚本模板，对之前收集到的目标文件进行扫描。演示环境是 Kali Linux 系统，所有相关脚本都已经放在指定文件夹中，课程资料会通过网盘分享给订阅用户。


用于检测操作系统的脚本示例如下：

![](img/bab6e912e8ca6537a92e01c2bd911558_16.png)

![](img/bab6e912e8ca6537a92e01c2bd911558_18.png)

```
nuclei -t smb-os-discovery -l SMB_IP.txt
```

![](img/bab6e912e8ca6537a92e01c2bd911558_20.png)

扫描完成后，你可能会发现目标系统属于 Windows Server 2012、Windows Server 2019，或者 Windows Server 2022。足迹分析部分到此结束，我们已经知道了目标的操作系统版本。


![](img/bab6e912e8ca6537a92e01c2bd911558_22.png)

知道了目标的操作系统，下一步就是检查这些目标是否开启了匿名访问。我们继续使用 nuclei 工具，这次加载的是专门针对 SMB 匿名访问的脚本模板，目标文件依然是 SMB_IP.txt。在接近 40 个目标中，大约有 3 个目标似乎开启了匿名访问，这意味着攻击者可以无需密码直接连接这些服务。


确认存在匿名访问之后，我们需要进一步查看这些目标共享了哪些文件夹。此时可以使用 Nmap 进行枚举，使用的脚本是 smb-enum-shares.nse。你需要对每一个目标进行枚举，在演示中我选择第三个目标，因为前两个目标没有什么有价值的信息。


![](img/bab6e912e8ca6537a92e01c2bd911558_24.png)

针对第三个目标的 Nmap 枚举命令示例如下：

![](img/bab6e912e8ca6537a92e01c2bd911558_26.png)

```
nmap -p 445 --script smb-enum-shares <目标IP>
```

![](img/bab6e912e8ca6537a92e01c2bd911558_28.png)

![](img/bab6e912e8ca6537a92e01c2bd911558_29.png)

执行完成后，你可以看到 445 端口是开启的，并且枚举出了 admin$ 和 IPC$ 等共享资源。这些内容属于攻击框架中远程会话枚举的一部分，也是后续利用错误配置的重要依据。


Nmap 只是告诉我们有哪些共享目录，接下来我们要用 SMB 客户端亲自去测试这些共享的读写权限。你需要使用 SMB 客户端工具，加上 -N 参数实现匿名连接，然后指定目标主机和共享名称，比如 admin$ 或 IPC$。


![](img/bab6e912e8ca6537a92e01c2bd911558_31.png)

使用 SMB 客户端匿名连接的命令示例如下：

![](img/bab6e912e8ca6537a92e01c2bd911558_33.png)

```
smbclient -N //<目标IP>/IPC$
```

连接成功后，你可以使用 help 命令查看可用操作，也可以使用 show connect 命令确认当前会话的内容。通过这种方式，我们就拿到了一个匿名的 SMB shell 会话，可以在其中浏览共享目录。


既然已经进入了匿名 SMB 会话，我们就可以尝试浏览目录并下载敏感文件了。首先使用 ls 命令显示当前目录下的所有文件夹，你会看到有多个目录。接下来可以使用 Tab 键自动补全长文件名或目录名，快速导航到感兴趣的文件夹，比如 E:\64\PCCC。


在目标系统中导航和下载文件的常用命令如下：

![](img/bab6e912e8ca6537a92e01c2bd911558_35.png)

```
ls
cd E:\64\PCCC
get <文件名>
```

![](img/bab6e912e8ca6537a92e01c2bd911558_37.png)

演示中已经下载了一个名为 PAR_N 的文件，文件大小大约是 2566 KB。你可以验证下载是否成功，也可以删除文件后重新下载，确认文件能够重新出现在本地目录中。这就是利用远程服务匿名访问成功获取敏感文件的完整过程。


![](img/bab6e912e8ca6537a92e01c2bd911558_39.png)

下载文件只是第一步，如果目标的读写权限允许，攻击者还能做更多事情。你可以继续导航到 admin$、IPC$ 等敏感共享，根据读写权限获取更多敏感信息。就像下载文件一样，我们也可以上传反弹 shell 文件到目标系统，从而实现对服务器的完全接管。


![](img/bab6e912e8ca6537a92e01c2bd911558_41.png)

本节课中我们一起学习了 SMB 协议的基本概念、常见错误配置，以及如何使用搜索引擎、nuclei、Nmap 和 SMB 客户端完成从目标发现、操作系统探测、匿名访问检查、共享目录枚举，到敏感文件下载的完整攻击流程。希望你喜欢本次演示，我们下次课见。
