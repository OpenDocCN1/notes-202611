
# 道德黑客完整课程 2026：32：键盘记录器 Beelogger 安装教程 🔑

## 课程概述

在本节课中我们将要学习如何安装和使用 Beelogger 键盘记录器工具。Beelogger 是一种可以记录目标计算机上所有按键操作的脚本，它会把记录下来的按键内容发送到指定的 Gmail 邮箱中。我们会一起了解这个工具的基本工作原理，然后从 GitHub 下载源代码，在 Linux 终端里完成安装，接着创建一个临时邮箱来接收日志，最后生成可执行文件并发送给目标机器。整个操作过程会比较长，中间很可能会遇到各种报错提示，请大家务必耐心跟随每一个步骤进行练习，不要因为报错就轻易放弃。

## 什么是键盘记录器

键盘记录器是一类专门用来捕获键盘输入的软件或脚本。当目标人员在电脑上敲击键盘时，所有按下的按键都会被悄悄记录下来，然后发送回攻击者控制的接收端。这个过程可以用一个简单的公式来表示：

![](img/a0ac9ac4419c55f62e960f35639a2fec_1.png)

按键输入 → 键盘记录器捕获 → 日志保存 → 发送到指定邮箱

Beelogger 就是其中一种键盘记录脚本，它会把受害者输入的账号密码等敏感信息直接发送到你设置的 Gmail 地址里。比如目标在输入 Facebook 的账号和密码时，这些信息都会被完整记录并发送过来。

![](img/a0ac9ac4419c55f62e960f35639a2fec_3.png)

![](img/a0ac9ac4419c55f62e960f35639a2fec_5.png)

这个工具提供的功能包括每 120 秒发送一次日志，或者在累积 50 个字符时立即发送，同时还内置了一些钓鱼方式，支持多会话操作，并且禁止了自动持久化功能。Beelogger 目前只对拉丁语系语言提供官方支持，安装和使用时请注意这一限制。

使用这个工具必须遵守法律和道德规范，只能用于合法的渗透测试和安全研究，绝对不能用于任何违法犯罪活动。所有使用后果由操作者自行承担，教程作者不对滥用行为负责。

## 获取 Beelogger 源代码

以下是获取 Beelogger 源代码的具体操作步骤。

1. 打开 Firefox 浏览器。
2. 在 GitHub 上搜索 Beelogger 项目页面。
3. 确认你访问的是官方网站，不要从其他不可信的地方下载。
4. 复制项目的克隆链接。

在下载源代码之前，建议先切换到 root 终端，因为 root 权限拥有更高的系统访问权限，可以更方便地安装软件。你可以通过切换用户命令进入 root 终端，获得完整的系统控制权限。进入 root 终端后，就可以开始下一步的安装操作了。

如果你在安装过程中遇到任何问题，可以参考 YouTube 上的安装视频，或者使用搜索引擎查找解决方案。搜索引擎在解决安装报错时非常有用，建议把它当成好朋友来对待，遇到不懂的报错直接去搜索就能找到答案。

## 在终端中安装依赖

![](img/a0ac9ac4419c55f62e960f35639a2fec_10.png)

![](img/a0ac9ac4419c55f62e960f35639a2fec_12.png)

以下是安装所需依赖环境的命令列表。

```bash
# 切换到 root 终端以获得更高权限
su

# 进入桌面目录
cd Desktop

# 克隆 Beelogger 项目
git clone https://github.com/.../beelogger.git

# 进入项目文件夹
cd beelogger

# 查看文件列表
ls

# 给安装脚本添加执行权限
chmod +x install.sh

# 运行安装脚本
./install.sh
```

安装过程中需要先安装 Python 和 Wine，这两个组件是让脚本在 Linux 环境下正常运行的基础。Python 用于执行脚本代码，而 Wine 则允许在 Linux 系统中运行 Windows 程序。整个安装过程可能需要四到十分钟不等，具体时间取决于你的网络速度和机器性能。如果出现连接超时或下载失败，请先更新操作系统，然后再重新尝试安装，通常多试几次就能成功。

## 配置 Gmail 接收日志

![](img/a0ac9ac4419c55f62e960f35639a2fec_17.png)

以下是配置邮箱以接收按键日志的注意事项。

![](img/a0ac9ac4419c55f62e960f35639a2fec_19.png)

- 不要使用你个人常用的 Gmail 账号。
- 请新建一个临时的 Gmail 账号用于测试。
- 注册时不要填写真实姓名或手机号码。
- 如果临时邮箱服务不可用，可以直接去注册一个普通的 Gmail 邮箱。

Beelogger 会将记录到的按键日志每 120 秒发送一次，或者在达到 50 个字符时发送，所有日志都会发送到你设置的这个 Gmail 地址中。使用临时邮箱可以保护你的个人隐私，避免泄露真实身份信息。请记住，Gmail 可能会提示你开启不安全应用的访问权限，否则日志可能无法正常发送。

![](img/a0ac9ac4419c55f62e960f35639a2fec_21.png)
