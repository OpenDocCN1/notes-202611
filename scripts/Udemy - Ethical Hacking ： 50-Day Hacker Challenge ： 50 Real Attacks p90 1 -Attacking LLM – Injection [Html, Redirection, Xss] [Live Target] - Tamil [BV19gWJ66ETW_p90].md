## 1. 注入的基本定义

上一节我们介绍了渗透测试的基础概念，本节中我们先来看看注入攻击的定义相关内容。注入攻击是指攻击者将不可信数据发送到解释器，从而改变程序原本的执行逻辑。我们不再花费大量时间去定义概念。出于随机的原因，之前已经有多个表格记录了与注入相关的数据。

以下是注入载荷的基本表达形式：

```text
注入载荷 = 用户输入 + 恶意指令
```

![](img/e73073eae7d6909842b48b0162d74cb3_4.png)

注入类型可以用代码列表表示：

![](img/e73073eae7d6909842b48b0162d74cb3_6.png)

```python
injection_types = ["HTML 注入", "重定向注入", "XSS 注入"]
```

这里不需要去记太多复杂的专业术语，你只要知道注入就是把坏东西塞进程序里执行就行。
