
# Data Analysis with Polars and Python：44：没有索引也没关系 🔢

在本节课中，我们将学习 Polars 数据框中索引的相关内容。如果你之前使用过 pandas，一定对索引这个概念不陌生。不过 Polars 的默认行为和 pandas 不一样，它的数据框原本没有索引，但提供了非常方便的方法让你手动添加。我们会一起看看如何创建索引列、如何修改起始数字、如何自定义列名，甚至可以在读取 CSV 文件的时候直接把索引带上。



在介绍 Polars 的具体操作之前，本节中我们先来聊聊索引到底是什么东西。



如果你之前使用过 pandas 库，那么你大概率已经熟悉索引这个概念了。索引就是数据框左边的一串递增数值。它的作用是给数据集里的每一行分配一个唯一的标识符。



在 pandas 里，标准的数字索引是这样工作的：第一行被分配到位置 0，第二行是位置 1，一直延续到数据框的最后一行。这个思路和 Python 列表里的索引位置非常相似。列表中的每个元素，同样会被分配一个数字顺序，也就是索引位置，而且是从 0 开始计数的。



你可以把索引理解为下面这样的结构：

```python
# Python 列表的索引位置
my_list = ["苹果", "香蕉", "橘子"]
# 索引分别是：0, 1, 2
```



刚才我们聊了 pandas 的索引，本节中我们来看看 Polars 到底怎么处理这个问题。



默认情况下，Polars 的数据框是没有任何索引的。不过，有一个非常方便的方法叫做 `with_row_index`，可以用来创建索引。



我会先重新执行上一课的代码，把我们的 employees 数据框导入进来。然后，我可以直接在 employees 数据集上调用 `with_row_index` 方法。



调用这个方法之后，会发生以下几件事：

- 它会在数据框里自动新建一列。
- 这一列会出现在左侧，默认列名叫做 `index`。
- 这一列的数据类型是无符号整数，因为索引值永远不会是负数，只能是 0 或正数。
- 索引会从 0 开始，给每一行分配一个排队的数字顺序。



如果你不想要从 0 开始的索引，这里有一个很好用的参数，叫做 `offset`。它的作用是设置索引的起始值，也就是你开始计数的数字。



比如，`offset` 的默认值就是 0，这就是我们刚才看到的效果。但如果我提供参数 1，并调用 `head` 方法来预览前五行，你会发现左边还是会出现那一列索引，只不过计数会从 1 开始。这样每一行都有一个很好用的数字标识符，有点像行号。



当然，如果你想，也可以提供一个任意值，比如 58。假设你有一组数据，其中一些数据丢失了，你想标注 Nicholas Maldonado 是公司第 58 个入职的员工，那么你完全可以让索引从你想要的任意数值开始。



如果你想自定义这一列的名字，不想用默认的 `index`，这里也有一个很好用的参数，叫做 `name`。比如，我可以把 `name` 设置为字符串 `I`，这时你会看到第一行的索引是 58，而列名变成了 `I`。



使用 `offset` 和 `name` 参数的代码示例如下：

```python
import polars as pl

df = pl.read_csv("employees.csv")
df_with_index = df.with_row_index(offset=1, name="I")
```



刚才我们学习了如何在数据框上调用方法来添加索引，本节中我们来看看另一种方式，即在读取文件的时候直接指定。



其实，以上所有操作都可以在 `with_row_index` 方法里完成，但你也可以在导入数据的时候直接指定数字索引。具体来说，你可以自定义 `read_csv` 函数的参数，让它自动把索引列附加上来。



这里我再次调用 Polars 库的 `read_csv` 函数，传入 employees 的 CSV 文件。这一次，我来展示这里有一个可用的参数，叫做 `row_index_name`，就在这里。



关于 `row_index_name` 参数，需要注意以下几点：

- 默认情况下，它的参数是 `none`，这意味着不会创建行索引。
- 但如果你给它一个名字，Polars 就会自动在左边加上那一列索引。



比如，我同样给它起个名字叫做 `ID`，你可以看到左边生成了一列，从 0 开始计数。



同样，还有一个参数叫做 `row_index_offset`。它的作用是设置起始数字，也就是起始索引位置。所以，如果我想从 1 开始计数，而不是默认的 0，我可以传递参数 1。



使用这两个参数的代码示例如下：

```python
df = pl.read_csv(
    "employees.csv",
    row_index_name="ID",
    row_index_offset=1
)
```



现在，我左边有一列 ID，充当索引列，从 1 开始计数。



好了，这就是如何在 Polars 数据框里添加相当于 pandas 索引的方法了。



本节课中，我们一起学习了 Polars 数据框默认没有索引，如何使用 `with_row_index` 方法手动创建索引列，如何通过 `offset` 参数修改起始数字，如何通过 `name` 参数自定义列名，以及如何在调用 `read_csv` 导入数据时，直接通过 `row_index_name` 和 `row_index_offset` 参数自动附加索引列。希望这些内容能帮助你更好地理解和使用 Polars 中的行索引。
