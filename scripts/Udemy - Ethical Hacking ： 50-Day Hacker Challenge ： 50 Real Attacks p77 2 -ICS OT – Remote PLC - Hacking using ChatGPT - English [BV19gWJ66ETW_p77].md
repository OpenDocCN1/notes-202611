## 二、第一步：在互联网上定位 PLC 设备 🌐

有了可用的环境之后，我们就要开始寻找目标了。在 ICS OT 攻击框架中，初始接入通常发生在面向外部的远程服务上，也就是说，那些可以直接从公网访问的工业设备成为了攻击者关注的重点。这一次演示的核心场景就是利用面向互联网的 PLC 设备进行攻击。

很多工业设备虽然内部是隔离的，但在实际部署中，出于远程维护的需要，部分 PLC 会被配置为可通过 Web 界面从外部访问。这就为我们提供了切入点。以下是寻找 PLC 设备的具体方法：

1. 使用 NSA 开源的 L 工具，该工具包含大量对工业控制系统有帮助的信息；
2. 在工具中检索艾伦布拉德利或罗克韦尔自动化等厂商的 PLC 文档，这些厂商的设备通常提供 Web 管理界面；
3. 检索 TCP 连接表，查找面向互联网的 PLC 设备及其本地 IP 地址。

当我们查询到 TCP 连接表后，会看到类似下面的信息：本地 IP 地址属于某台 Rockwell PLC，远程地址通过特定端口与其建立连接，这些端口通常属于以太网/IP 协议族，例如端口 44818。这就好比我们在互联网上扫描了一遍，找到了一台亮着灯的 PLC 设备，并且知道了它的 IP 地址和开放端口。

## 三、第二步：使用 ChatGPT 编写端口扫描工具 📡

![](img/5a9a5a0a99eb345b82b88d54656a6509_24.png)

在确定了目标 PLC 的 IP 地址之后，接下来的工作就是检查这个设备上开放了哪些端口。开放端口就像是房间的门窗，告诉我们攻击者可以从哪里进入。

我们不需要手动去扫描全部 65535 个端口，因为全量扫描很容易触发安全设备的告警，产生大量噪音。更聪明的做法是只扫描工业控制系统常用的几个端口，这样既高效又隐蔽。以下是使用 ChatGPT 编写端口扫描脚本的思路：

![](img/5a9a5a0a99eb345b82b88d54656a6509_26.png)

- 指定目标 IP 地址；
- 只扫描预先选定的工业协议端口，例如 44818、8080 等；
- 输出扫描结果，标记哪些端口是开放的。

![](img/5a9a5a0a99eb345b82b88d54656a6509_28.png)

![](img/5a9a5a0a99eb345b82b88d54656a6509_29.png)

我们可以让 ChatGPT 直接生成一段 Python 脚本，然后保存为本地文件。运行脚本后，你会看到类似下面的输出：

![](img/5a9a5a0a99eb345b82b88d54656a6509_31.png)

![](img/5a9a5a0a99eb345b82b88d54656a6509_33.png)

![](img/5a9a5a0a99eb345b82b88d54656a6509_35.png)

```
Port 8 is open
Port 44818 is open
Port 8080 is open
```

![](img/5a9a5a0a99eb345b82b88d54656a6509_37.png)

这说明目标 PLC 上确实开放了这些工业控制端口，其中 44818 是典型的 Rockwell EtherNet/IP 端口，进一步证实了目标是一台面向互联网的 PLC 设备。

## 四、第三步：探测关联远程 IP 并查询地理位置 🧭

![](img/5a9a5a0a99eb345b82b88d54656a6509_42.png)

有了目标 PLC 的开放端口之后，我们还可以进一步挖掘。TCP 连接表不仅显示了本地设备，还记录了与之建立连接的远程 IP 地址。这些远程 IP 很可能属于同一个工业控制网络中的其他 PLC 设备，或者是远程维护工作站。

![](img/5a9a5a0a99eb345b82b88d54656a6509_44.png)

![](img/5a9a5a0a99eb345b82b88d54656a6509_46.png)

我们可以把这些远程 IP 当作新的线索，进一步探测它们的物理位置。为了自动化这个过程，我们可以让 ChatGPT 编写一个 Python 脚本，完成以下任务：

![](img/5a9a5a0a99eb345b82b88d54656a6509_48.png)

- 定时刷新某个包含 IP 列表的页面，例如每隔 60 秒刷新一次；
- 提取页面中出现的所有 IP 地址；
- 对每个 IP 地址查询地理位置信息。

在实际操作中，最初尝试使用某些地理位置库时可能会遇到错误，例如提示该库不是为 IP 地址位置设计的。此时我们可以切换到不需要 API 密钥的免费查询服务，比如 ip-api.com，这样就可以绕过注册账号和申请密钥的麻烦。

最终得到的结果会列出 IP 地址及其对应的地理位置，例如：

![](img/5a9a5a0a99eb345b82b88d54656a6509_52.png)

## 五、第四步：生成 PLC 地理位置分布地图 🗺️

当我们收集到多个 IP 地址及其地理位置后，如果只是一堆文字，很难直观地理解这些设备分布在哪里。这时候，把这些信息绘制成世界地图会更加直观。

![](img/5a9a5a0a99eb345b82b88d54656a6509_64.png)

我们可以让 ChatGPT 继续编写脚本，完成以下功能：

![](img/5a9a5a0a99eb345b82b88d54656a6509_66.png)

![](img/5a9a5a0a99eb345b82b88d54656a6509_68.png)

![](img/5a9a5a0a99eb345b82b88d54656a6509_70.png)

- 读取之前提取并解析好的 IP 地址列表；
- 将每个 IP 的地理位置标记在地图上；
- 使用不同颜色的点来区分不同类型的设备，比如红点和蓝点。

![](img/5a9a5a0a99eb345b82b88d54656a6509_72.png)

![](img/5a9a5a0a99eb345b82b88d54656a6509_73.png)

运行脚本后，会生成一个 HTML 地图文件。打开这个文件，你就能在上面看到各个 IP 地址对应的地理位置点。例如，你可以在地图上清晰地看到一个位于芝加哥的点，对应的就是之前发现的使用 44818 端口的 PLC 设备。

这样，原本分散的 IP 地址和端口信息，就被串联成了一张完整的工业设备分布图，攻击者可以一目了然地掌握目标区域的攻击面。
