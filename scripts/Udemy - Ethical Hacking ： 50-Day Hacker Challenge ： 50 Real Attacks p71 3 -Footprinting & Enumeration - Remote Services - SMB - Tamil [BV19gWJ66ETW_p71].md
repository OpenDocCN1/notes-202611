## 远程服务与 SMB 基础

![](img/e1df665e10b4f462c9d496d9e6334897_6.png)

上一节我们介绍了信息收集的基础概念，本节中我们来看看远程服务中的 SMB 协议。

![](img/e1df665e10b4f462c9d496d9e6334897_8.png)

远程服务是指运行在网络其他主机上的服务，常见的有 SMB 等。在目标网络中，通常会包含一些隐藏共享，例如 C$ 和 IPC$，这些共享带有美元符号 $，可以用来进行远程访问并获取关键信息。我们需要理解这些共享的存在，才能在后续枚举中找到突破口。查询这些共享时，不需要在目标主机上上传任何文件，也不需要预先加载额外工具。

![](img/e1df665e10b4f462c9d496d9e6334897_10.png)

以下是远程服务中常见的隐藏共享示例：
- C$：系统盘根目录的隐藏共享
- IPC$：用于进程间通信的命名管道共享
- ADMIN$：远程管理共享


![](img/e1df665e10b4f462c9d496d9e6334897_12.png)

## 匿名访问与 SMB 枚举

![](img/e1df665e10b4f462c9d496d9e6334897_14.png)

了解了远程服务的基本共享后，本节中我们来看看如何利用匿名访问对 SMB 服务进行枚举。

在目标环境中，有些系统开启了匿名访问，这意味着不需要账号密码就能连接。我们可以直接访问目标上的共享资源，几乎在所有相关链接中都能尝试匿名方式。匿名访问属于脚本扫描范围，或者是在我们感兴趣的时间段内完成的脚本操作，目的是完成对目标的全部脚本扫描。目标系统可能运行 Windows 10、Windows Server 2022 或 2016 等版本，不同版本的共享权限可能有所不同。

以下是匿名访问的基本步骤：
1. 确认目标运行 Windows 10、Windows Server 2022 或 2016 等版本
2. 使用空凭据尝试连接目标主机
3. 列出可访问的共享资源
4. 记录发现的条目，通常会有 40 多个左右

![](img/e1df665e10b4f462c9d496d9e6334897_18.png)

## 脚本扫描与端口探测

![](img/e1df665e10b4f462c9d496d9e6334897_20.png)

完成匿名访问后，本节中我们来看看如何使用脚本工具扫描 SMB 端口并获取完整结果。

![](img/e1df665e10b4f462c9d496d9e6334897_21.png)

![](img/e1df665e10b4f462c9d496d9e6334897_22.png)

![](img/e1df665e10b4f462c9d496d9e6334897_24.png)

在实际渗透测试中，从某个目标出发，通常能发现 40 多个开放端口或服务条目。第三个目标上可能已经识别出编号为 1172 的服务或漏洞，查看完整结果可能需要一些时间。此时我们可以运行专门的 SMB 脚本，并将端口设置为 445，这是 SMB 服务的默认端口，同时涉及带 $ 符号的隐藏共享。脚本扫描能够自动化地探测目标上的 SMB 服务状态，减少人工操作的失误。

![](img/e1df665e10b4f462c9d496d9e6334897_26.png)

以下是常用 SMB 脚本扫描命令示例：
```bash
nmap --script smb-enum-shares -p 445 <目标IP>
```

## 本地凭据与文件枚举

![](img/e1df665e10b4f462c9d496d9e6334897_29.png)

![](img/e1df665e10b4f462c9d496d9e6334897_30.png)

脚本扫描结束后，本节中我们来看看如何提取本地凭据并枚举文件信息。

在预防措施方面，我们需要注意本地凭据的安全性。有些系统会将本地凭据存储在配置文件中，攻击者可以列出这些本地信息。在面板界面中，我们可以加载 64 位版本的工具，查看 PNR 0.0.1 等条目，并创建相应的面板字段。在文件设置中，可能会出现本地或下载注释的问题，需要逐一排查，避免包含无关成分，只保留有效凭据。

以下是本地凭据枚举的关键点：
- 检查 Maria 文件中的配置条目
- 记录面板字段和剪切按钮操作
- 避免包含无关成分，只保留有效凭据


![](img/e1df665e10b4f462c9d496d9e6334897_32.png)

## 远程会话与足迹分析实战

![](img/e1df665e10b4f462c9d496d9e6334897_34.png)

完成凭据提取后，本节中我们来看看如何建立远程会话并进行足迹分析。

获取相关信息后，我们可以获取目标系统的照片或截图，确认 HP 等硬件信息已被密封保护。如果在主机声明中发现相关条目，意味着这些信息存在于文件内部。即使不是本地系统，也可以尝试下载 Pto 文件，并进行复制操作，涉及菲律宾本地节点或 3D 打印相关数据。通过点击 SMB 远程服务中的足迹文件，我们可以建立远程会话，享受完整的枚举结果。

以下是建立远程会话的步骤：
1. 点击 SMB 远程服务中的足迹文件
2. 连接文件中的文件，使用双点路径符号 ..
3. 确认主机声明和文件内部数据
4. 享受远程会话，完成足迹分析
