上一节我们介绍了渗透测试的通用流程，本节中我们来看看工业控制系统里的远程 PLC 攻击。工业控制系统通常缩写为 ICS，是用来监控和控制物理设备的系统，常见于工厂、电厂和水处理厂。PLC 是可编程逻辑控制器，相当于工业设备的大脑，负责读取传感器数据并发送控制指令。OT 是运营技术，与 IT 信息技术不同，OT 更关注实际的硬件设备运行。当这些设备连接到互联网时，就可能面临远程攻击的风险。

第一步：在互联网上查找 PLC 设备

在了解了基本概念之后，我们进入实际操作。以下是查找公开 PLC 设备的常见方法：

- 使用搜索引擎语法，查找暴露在公网上的 PLC Web 界面
- 检查常见工业协议端口，例如 448、5200、6400、8285
- 通过公开 IP 地址数据库，确认目标设备的归属地区
- 结合 ChatGPT 生成查询语句，快速定位潜在目标

以示例 IP 166.0.177.17 为例，我们可以在搜索框中输入相关关键词，查看该设备是否开放了远程访问接口。如果页面能正常加载，说明该 PLC 暴露在公网上，进一步攻击面就会增大。

第三步：提取 IP 地理位置并生成映射

获取目标 IP 地址后，下一步是将其转换为地理位置，方便可视化分析。以下是具体操作步骤：

- 提取返回结果中的国家、州和城市信息
- 将提取的坐标写入地图数据文件

例如，针对 IP 166.0.177.17，系统可能显示其位于美国境内，并在地图上标出一个点。不同 IP 对应不同的地理位置点，这些点可以帮助我们了解目标设备的实际部署区域，进一步制定远程接入策略。

第四步：使用 Python 脚本自动化数据提取

![](img/6a5337bdf72088b2e34ff3dc6b4950f7_59.png)

![](img/6a5337bdf72088b2e34ff3dc6b4950f7_61.png)

手动查找效率较低，可以用 Python 脚本批量处理 IP 地址和连接信息。以下是示例代码结构：

![](img/6a5337bdf72088b2e34ff3dc6b4950f7_63.png)

![](img/6a5337bdf72088b2e34ff3dc6b4950f7_65.png)

![](img/6a5337bdf72088b2e34ff3dc6b4950f7_66.png)

```python
import requests
import socket

def get_geo_location(ip):
    url = f"https://ipapi.co/{ip}/json/"
    response = requests.get(url)
    data = response.json()
    return {
        "ip": ip,
        "country": data.get("country_name"),
        "city": data.get("city"),
        "latitude": data.get("latitude"),
        "longitude": data.get("longitude")
    }

target_ip = "166.0.177.17"
result = get_geo_location(target_ip)
print(result)
```

![](img/6a5337bdf72088b2e34ff3dc6b4950f7_68.png)

这段脚本的作用是输入一个有效的 IP 地址，调用外部接口获取地理位置信息，并将结果打印出来。你可以将脚本中的 target_ip 替换为你发现的任何 PLC 公网 IP，运行后即可得到该设备所在的国家与城市。脚本执行时间通常在几十秒之内，具体取决于网络延迟和 API 响应速度。

脚本运行完成后，会生成一个包含 IP 位置信息的文件。以下是结果分析方法：

![](img/6a5337bdf72088b2e34ff3dc6b4950f7_78.png)

生成的点图中，每个点代表一个提取到的 IP 地址所在的地理位置。如果点集中在某个国家或城市，说明该地区的工业设备暴露风险较高。攻击者或安全人员可以根据这些分布，判断哪些区域需要加强网络隔离和访问控制。
