
Polars 数据分析与 Python 入门：84：使用数学运算符进行过滤 📊

在本节课中，我们将要学习如何在 Polars 中使用数学运算符来过滤数据。上一节我们介绍了如何使用等号运算符筛选出等于特定值的行，本节中我们来看看不等于、大于、小于以及大于等于和小于等于这些常见运算符是怎么工作的。我们会继续使用咖啡数据集作为例子，讲解如何通过这些运算符筛选出符合条件的行，并且会对比运算符写法和对应方法写法，帮助你彻底掌握 Polars 的过滤逻辑。


## 一、不等于运算符与 ne() 方法 ❌

![](img/721498f575d5b9316f77a0bef8cb575a_1.png)

![](img/721498f575d5b9316f77a0bef8cb575a_2.png)

上一节我们介绍了等号运算符的基本用法，本节中我们来看看它的相反操作，也就是不等于运算符，以及它在 Polars 中的具体写法。

现在我们对 filter 方法的机制已经有了比较清晰的理解，接下来可以尝试用更多数学运算符来做过滤。首先我们先把咖啡数据框加载进来。在上一课中，我们学习过如何用等号运算符检查哪些行的值等于某个固定常量，而 Polars 同样提供了不等于运算符，它的符号和 Python 中完全一样，就是感叹号后面紧跟等号，写作 `!=`。

![](img/721498f575d5b9316f77a0bef8cb575a_4.png)

作为一个快速回顾，在 Python 里我们可以这样写：

```python
5 != 8
```

这行代码会返回等号运算符的相反结果。当两个值不相等时，结果是 `True`；当两个值相等时，结果是 `False`。也就是说，`!=` 是等号运算符的逆运算。

举例来说，假设我们现在查看咖啡数据框，想要筛选出奶类型不等于燕麦奶的行。也就是说，除了燕麦奶以外的所有奶类型都要保留。这里要再次提醒一点，如果数据中存在空值，在进行过滤时空值会被完全忽略，不会被保留也不会被排除进入布尔判断。

具体操作时，和往常一样，我们从 `filter` 方法开始，然后用 `pl.col` 针对奶类型列构建一个表达式，接着应用不等运算符 `!= "oat"`。这行代码的意思是，查找奶类型列中不等于字符串 `oat` 的所有行。符合条件的行会被保留，不符合条件的行会被排除，这样一来我们就得到了一个新的筛选后数据框，里面只包含奶类型不等于 `oat` 的行。

除了直接使用 `!=` 符号，Polars 还提供了一个互补方法叫 `ne`，也就是 not equal 的缩写。使用方法也是先创建表达式，然后调用 `.ne("oat")` 来传入要比较的值。两种写法得到的数据框是完全一样的，只要记得把 `filter` 方法的括号闭合即可。

以下是不等于过滤的代码示例：

![](img/721498f575d5b9316f77a0bef8cb575a_6.png)

![](img/721498f575d5b9316f77a0bef8cb575a_7.png)

![](img/721498f575d5b9316f77a0bef8cb575a_8.png)

```python
import polars as pl

df = pl.read_csv("coffees.csv")

# 使用运算符
result_1 = df.filter(pl.col("milk_type") != "oat")

# 使用方法
result_2 = df.filter(pl.col("milk_type").ne("oat"))
```


## 二、大于与小于运算符 ⬆️⬇️

在了解了不等于运算符之后，本节中我们来看看更多常用的比较运算符，先从大于和小于开始。

![](img/721498f575d5b9316f77a0bef8cb575a_10.png)

![](img/721498f575d5b9316f77a0bef8cb575a_11.png)

![](img/721498f575d5b9316f77a0bef8cb575a_12.png)

![](img/721498f575d5b9316f77a0bef8cb575a_13.png)

当然，对于常见的数学运算，Polars 提供了大家都很熟悉的运算符，包括大于、小于、大于等于和小于等于，并且每个运算符都有对应的互补方法。让我们再次打开咖啡数据框来看具体例子。

![](img/721498f575d5b9316f77a0bef8cb575a_14.png)

我们先从 `price` 列开始，这是一个很适合做数值运算的列。比如说，我们想筛选出咖啡价格大于 5 美元的行。操作方式和之前一样，先针对 `price` 列，然后使用大于号 `>` 来查找价格值大于 5 的行。运行之后，你会看到结果中 `price` 列的所有值都大于 5。

大于符号 `>` 的互补方法是 `gt`，也就是 greater than 的缩写。使用时需要为 `gt` 方法加上一对括号，同时也要记得 `filter` 方法本身也要加括号。两种写法得到的数据框也是完全相同的。

![](img/721498f575d5b9316f77a0bef8cb575a_16.png)

下面是大于和小于的代码示例：

```python
# 价格大于 5
result_gt = df.filter(pl.col("price") > 5)
result_gt_method = df.filter(pl.col("price").gt(5))

# 价格小于 5
result_lt = df.filter(pl.col("price") < 5)
result_lt_method = df.filter(pl.col("price").lt(5))
```

如果把条件改成价格小于 5，就会得到一个相反的数据框。原文中提到筛选出了 617 行，这些行的价格都小于 5。需要注意的是，这里是严格小于，所以如果某一行的价格恰好就是 5，它也会被从结果中排除，不会被保留。


## 三、大于等于与小于等于运算符 ↔️

![](img/721498f575d5b9316f77a0bef8cb575a_18.png)

学完了大于和小于，本节中我们来看看包含“等于”情况的两个运算符，也就是大于等于和小于等于。

![](img/721498f575d5b9316f77a0bef8cb575a_19.png)

![](img/721498f575d5b9316f77a0bef8cb575a_20.png)

![](img/721498f575d5b9316f77a0bef8cb575a_21.png)

接下来我们把刚才的两行代码复制一份，用来演示大于等于的情况。大于等于运算符会匹配那些价格大于 5，或者恰好等于 5 的行。它的符号是尖括号后面跟等号，写作 `>=`。对应的互补方法是 `ge`，也就是 greater than or equal to 的缩写。即使数据里没有正好等于 5 的价格，结果中每一行的价格也都会大于或等于 5。

同样的，小于等于运算符的符号是 `<=`，对应的方法是 `le`，也就是 less than or equal to 的缩写。使用这个条件后，所有价格都会在 5 美元或以下。

以下是大于等于与小于等于的代码示例：

![](img/721498f575d5b9316f77a0bef8cb575a_23.png)

```python
# 价格大于等于 5
result_gte = df.filter(pl.col("price") >= 5)
result_gte_method = df.filter(pl.col("price").ge(5))

# 价格小于等于 5
result_lte = df.filter(pl.col("price") <= 5)
result_lte_method = df.filter(pl.col("price").le(5))
```

## 四、过滤背后的布尔逻辑 🧠

![](img/721498f575d5b9316f77a0bef8cb575a_27.png)

![](img/721498f575d5b9316f77a0bef8cb575a_28.png)

前面几个小节我们分别介绍了各种比较运算符，本节中我们来聊聊这些过滤操作背后共同的底层逻辑。

其实不管用哪个过滤操作，逻辑始终是一样的。我们创建一个表达式来针对某一列，然后想办法利用这一列的值，生成一个布尔列。这个布尔列里面全是 `True` 和 `False`，其中 `True` 表示该行应该被保留，`False` 表示该行应该被排除或丢弃。

从逻辑上讲，所有这些操作本质上都是布尔值，也就是对真假的评估。它们不会产生字符串、列表或数字，产生的只是一个 `True` 或 `False` 的真假判断。

如果你在写代码时感到困惑，不确定表达式是否正确，一个简单的提醒是，可以暂时把 `filter` 方法替换成 `select` 方法。这样一来，你会得到一列布尔值，只要这一列出来了，就能确认你构建的表达式数据类型是正确的，并且能传给 `filter` 方法使用。这也是 `filter` 方法能持续定位出需要提取的行的原因。

![](img/721498f575d5b9316f77a0bef8cb575a_30.png)

![](img/721498f575d5b9316f77a0bef8cb575a_31.png)

以下是用 select 查看布尔列的示例：

```python
# 用 select 查看过滤条件生成的布尔列
boolean_column = df.select(pl.col("price") > 5)
```
