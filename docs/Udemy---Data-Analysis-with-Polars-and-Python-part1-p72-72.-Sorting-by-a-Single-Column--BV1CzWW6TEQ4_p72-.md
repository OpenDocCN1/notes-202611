
📘 Polars与Python数据分析：第72节：按单列排序

![](img/a6d232f1e997e29109fbccd482d6dbde_1.png)

在本节课中，我们将一起学习如何使用Polars对单个列进行排序。排序是数据分析中最常见的操作之一，我们经常会需要把数据按照某个字段排一下顺序，方便观察规律。本节课会介绍Polars中默认的升序排序、如何实现降序排序、缺失值在排序时的默认位置以及如何调整、大小写字母的排序规则，最后还会看看在表达式上直接调用sort方法会有什么不同效果。通过这些内容，你可以彻底掌握Polars中按单列排序的基本用法。

首先，我们还是按照老规矩，先把数据集准备好。在之前的课程中，我们已经把员工数据载入到了一个名为employees的数据框中。现在，我们就以这个数据框为例，开始学习排序操作。Polars提供了一个名字非常直白的排序方法，叫做sort。我们只需要在数据框后面调用这个方法，并告诉它要对哪一列排序，就可以完成排序操作。

### 1. 默认排序顺序：升序

在动手写代码之前，先来了解一下Polars中默认的排序规则。Polars的sort方法默认是按照升序（ascending）排列的。所谓升序，针对不同数据类型有不同含义。对于数字来说，升序就是从最小的值排到最大的值；对于字符串来说，升序就是按照字母表顺序从A排到Z；对于日期来说，升序则是从最早的日期排到最晚的日期。简单概括如下：

![](img/a6d232f1e997e29109fbccd482d6dbde_3.png)

```python
# 数字：升序 = 从小到大
# 字符串：升序 = 字母表从A到Z
# 日期：升序 = 从早到晚
```

这个默认规则非常容易理解，后续的示例都会基于这个规则展开。当我们把一个列按升序排列后，数据框的行也会跟着这个排序结果一起移动，也就是说，排序后第一行就是该列值最小的那一行，最后一行的值最大。理解这一点非常重要，因为很多时候我们不只是想看一列单独排序的结果，而是希望整个数据框的行都按照某一列的顺序重新排列。

![](img/a6d232f1e997e29109fbccd482d6dbde_5.png)

### 2. 对数值列进行升序排序

![](img/a6d232f1e997e29109fbccd482d6dbde_6.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_7.png)

我们先来看一个最简单的例子：对salary列进行排序，让工资从低到高排列。实现方法非常简单，只需要在sort方法中传入一个字符串形式的列名即可。

![](img/a6d232f1e997e29109fbccd482d6dbde_9.png)

```python
employees.sort("salary")
```

![](img/a6d232f1e997e29109fbccd482d6dbde_10.png)

运行这一行代码后，我们会得到一个新的数据框。从结果中可以看到，Brittany Garrison是工资最低的员工，所以她的记录排在了第一行。随后，工资会从小到大逐渐递增，一直排到新数据框的最后一行，那里就是整个数据集中工资最高的记录。这整个过程非常直观，数据框的行顺序完全由salary列的大小决定。

![](img/a6d232f1e997e29109fbccd482d6dbde_12.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_13.png)

当然，除了直接传入字符串列名，我们还可以用另一种方式，那就是传入一个Polars表达式。具体做法是用pl.col()把列名包起来，就像下面这样：

![](img/a6d232f1e997e29109fbccd482d6dbde_15.png)

```python
employees.sort(pl.col("salary"))
```

这样写并没有任何特别的优势，但它完全合法，而且得到的结果和刚才一模一样。之所以介绍这种写法，是因为Polars中很多方法都同时接受字符串和表达式两种形式，熟悉这两种写法会让你在后续的学习中更加灵活。你可以随便挑一种自己顺手的写法，二者在功能上并没有差别。

### 3. 对字符串列进行升序排序

接下来再看一个补充例子，这次我们选择一个字符串列，比如name列。语法和刚才完全一样，调用sort方法，传入一个字符串列名，只不过这次我们把目标改成"name"。

![](img/a6d232f1e997e29109fbccd482d6dbde_17.png)

```python
employees.sort("name")
```

![](img/a6d232f1e997e29109fbccd482d6dbde_19.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_20.png)

执行这段代码后，我们会得到一个按字母顺序排列的结果。名字从A开头开始，一路排到Z开头。这个排序结果看起来很整齐，也很符合我们对字符串排序的预期。有一点需要提前说明，大小写字母在排序时会有一些特殊的处理方式，我们会在本节课的后面专门讲到。不过目前看到的例子中，所有名字的首字母都是大写，所以排序结果和普通字典顺序一致。

为了再演示一次表达式写法，我也可以把这个字符串包在pl.col()函数调用中：

![](img/a6d232f1e997e29109fbccd482d6dbde_22.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_23.png)

```python
employees.sort(pl.col("name"))
```

效果和刚才一模一样。看到这里，你可能会发现，sort方法的用法其实非常简单，传入列名就能完成排序。接下来，我们需要深入了解一个和排序方向密切相关的参数，这个参数在很多实际场景中都会用到。

### 4. 认识descending参数

![](img/a6d232f1e997e29109fbccd482d6dbde_25.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_26.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_27.png)

在继续往下看之前，有一个关于默认排序的重要参数需要了解，它就是sort方法中的descending参数。descending是“下降”的意思，正好和ascending（上升）相对。你可以看到，这个参数默认值是False。正因为默认情况下不是降序，所以sort方法才会默认执行升序排序，也就是从小到大。如果你想把升序这个意图明确地写出来，也可以等价地写成descending=False。我们刚才对name列做的排序，就是升序排序，并不是降序排序。

对于字符串列来说，升序是从A排到Z；对于数值列，无论是整数还是浮点数，升序都是从最小值排到最大值。理解这个参数的意义后，我们再来看看日期列的情况。员工数据中恰好有一个很方便的日期列，叫做start date。我们可以对这个日期列做一次升序排序，看看会得到什么结果。

```python
employees.sort("start date")
```

日期升序的含义是，从最早的日期排到最晚的日期。所以排序后，最早入职的员工会排在最前面，然后时间一路向后推进，直到最新的入职日期出现在数据框的最后。这个过程和数值排序本质上是一样的，都是按照某种顺序把数据进行排列。

![](img/a6d232f1e997e29109fbccd482d6dbde_29.png)

### 5. 使用降序排序

![](img/a6d232f1e997e29109fbccd482d6dbde_30.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_31.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_32.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_33.png)

看完了升序，接下来当然要看看反过来排的效果，也就是降序排序。降序排序的方向正好和升序相反：从最大值排到最小值，或者从字母表末尾排到开头，又或者从最新日期排到最早日期。实现方式也完全一样，只需要把descending参数设为True即可。

这次我们稍微换一种写法，使用表达式来传入列名。当然，使用字符串列名也一样，两种写法的结果完全相同。我们先拿salary列举例。默认情况下，sort方法是升序，所以工资是从小到大排列。如果我们在sort方法中把descending参数设置为True（这个参数默认是False），就相当于要求数据框按照salary列降序排列。

```python
employees.sort(pl.col("salary"), descending=True)
```

![](img/a6d232f1e997e29109fbccd482d6dbde_35.png)

现在得到的结果正好反过来了：新数据框的第一行是工资最高的记录，然后依次下降，最后一行是工资最低的员工。这个排序结果非常直观，适合用来找出工资最高的员工或者做排行榜之类的分析。

![](img/a6d232f1e997e29109fbccd482d6dbde_36.png)

既然数值列可以降序排列，字符串列当然也可以。我们再把同样的逻辑套用到name列上。name列是字符串列，降序就意味着反字母序。也就是说，从英文字母表的末尾开始，倒着排到开头。你可以看到，排在最前面的是Z开头的名字，然后一路倒排到A开头的名字。

不过，在实际的数据中，可能会有一些名字的首字母相同。遇到这种情况，Polars并不会随便排，而是会继续比较第二个字符，如果第二个字符也相同，就继续比较第三个字符，依此类推。这种排序方式和人类排序的习惯非常相似，所以结果通常非常符合直觉。从结果中可以看到，名字最终一路排到了A开头的记录。

类似地，如果对一个日期时间列做降序排序，比如start date列，我们得到的结果是，距离现在最近的日期（也就是最晚的日期）排在最前面。从时间线上看，就是时间从未来倒退回过去，最后一行是数据集中最早的日期。

![](img/a6d232f1e997e29109fbccd482d6dbde_38.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_39.png)

```python
employees.sort(pl.col("start date"), descending=True)
```

![](img/a6d232f1e997e29109fbccd482d6dbde_40.png)

这样一来，升序和降序的用法就都掌握了。总结一下，排序方向的控制完全取决于descending这个参数，把它设为False就是升序，设为True就是降序。不过，排序时还有另一个不容忽视的问题，那就是缺失值应该放在哪里。

### 6. 缺失值（null）的排序位置

![](img/a6d232f1e997e29109fbccd482d6dbde_42.png)

前面我们排序的所有列都是没有缺失值的，所以还没有遇到缺失值的问题。但实际数据处理中，数据集中往往会有一些缺失值，Polars当然也需要处理这些null值。有一个很重要的默认行为需要记住：在Polars的排序中，缺失值默认会被排在最前面。我们用一个具体的例子来说明。

![](img/a6d232f1e997e29109fbccd482d6dbde_44.png)

在我们的员工数据中，唯一有缺失值的列是department列。这个列存储的是部门名称，属于字符串类型。我们尝试按照department列排序：

```python
employees.sort("department")
```

从结果中可以看到，Polars首先会把所有null值集中放到最前面。这些null值之间可能是随机排列，也可能按照它们在原数据框中出现的顺序排列，具体是哪种情况，我不是特别确定。但关键点在于，null值确实排在了最前面。处理完这些null值之后，Polars才会对剩下的非空值做正常的字母升序排序，从字母A开始，一直排到最后一个部门，比如sales。所以最终结果是：null值在最前面，后面紧跟的是升序排列的部门名称。

![](img/a6d232f1e997e29109fbccd482d6dbde_46.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_47.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_48.png)

如果你希望null值出现在最后面，Polars也专门提供了一个参数来控制这个行为。这个参数的名字很贴切，叫做nulls_last。它的默认值是False，所以默认情况下缺失值会排在最前面。一旦你把nulls_last参数设置为True，Polars就会把null值放到数据框的最后位置。

![](img/a6d232f1e997e29109fbccd482d6dbde_49.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_50.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_51.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_52.png)

```python
employees.sort("department", nulls_last=True)
```

注意，这个设置并不会改变排序本身的方向，排序仍然是升序，部门名称依然按照字母顺序从C、E等字母开始，一直排列到sales。只是在排序完成后，Polars会把那些缺失值的记录统一放到末尾。换句话说，nulls_last只是调整缺失值的位置，不会影响其他值的排序结果。

![](img/a6d232f1e997e29109fbccd482d6dbde_54.png)

同样的原则也适用于降序排序。举个例子，如果我把descending参数设为True，表示要进行降序（反字母序）排序，但同时仍然要求null值放到末尾，那么排序会先执行反字母序，从字母表末尾一直排到A，排序完成后，Polars再把所有null值放到最后。这个组合使用起来非常灵活，你可以根据自己的需要自由调整。

![](img/a6d232f1e997e29109fbccd482d6dbde_56.png)

### 7. 大小写字母的排序规则

![](img/a6d232f1e997e29109fbccd482d6dbde_57.png)

前面我们提到过大小写字母的排序问题，现在就来仔细讲一讲。Polars处理大小写字母的算法和Python本身是一样的，这是这门语言自带的行为。具体规则是：在排序时，大写字母会排在小写字母之前。

为了说清楚这个规则，我举一个有点刻意但很容易理解的例子。我直接在Polars中创建一个Series，名字叫做fruits，里面包含三个值：大写A开头的"Apple"、小写b开头的"bananas"、大写P开头的"Pair"。

```python
s = pl.Series("fruits", ["Apple", "bananas", "Pair"])
s.sort()
```

这是原始Series。我们在Series上直接调用sort方法，不需要指定列名，因为Series本身就只有一列。这样做是完全可以的。但请注意排序结果：Polars会优先处理大写字母。大写A当然应该排在大写P之前，这很合理。但关键在于，所有大写字母都会排在任何小写字母之前。因此，"Pair"会排在小写b开头的"bananas"前面。如果数据中还有一个以小写a开头的"apple"，那么它会排在"Pair"之后、"bananas"之前。也就是说，在所有以大写字母开头的单词后面，但在任何以小写字母开头的单词前面。

![](img/a6d232f1e997e29109fbccd482d6dbde_59.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_60.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_61.png)

这个规则在排序时非常容易忽略，尤其是当你的字符串列中大小写混用的时候，结果可能会和你预期的不太一样。所以建议在排序前，先确认数据中的字符串是否已经统一了大小写形式。

### 8. 在表达式上调用sort方法

本节课最后要展示的内容虽然不太常用，但理解它有助于你搞清楚Polars中不同语法选项的区别。除了在数据框上调用sort方法，我们还可以在一个表达式上直接调用sort方法。不过需要注意的是，这两种调用方式完成的操作完全不同，这一点非常重要。

我们来看看下面的例子。我先把employees数据框取出来，调用with_columns方法，在with_columns里面针对salary列调用sort方法。请注意，这里并不是在employees数据框上调用sort，而是在salary这个表达式上调用sort。

```python
employees.with_columns(pl.col("salary").sort())
```

![](img/a6d232f1e997e29109fbccd482d6dbde_63.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_64.png)

这个操作的含义是：取出salary列，把这一整列的值按升序排列（从小到大），然后因为我没有提供别名（alias），生成的新列名仍然是salary，它会直接替换掉数据框中原有的salary列。关键在于，数据框的行顺序不会发生任何移动。你会发现，原本第一行的CEO Nicholas Maldonado仍然留在第一行。我们做的事情，只是把salary列里面的数字按照大小重新排了一遍，然后用这个排好序的列覆盖了原来的salary列。

所以，这些排好序的工资数字并不是原来那些员工对应的工资，它们只是被排序后的工资序列，再和原数据框的其他行拼接在一起，这是with_columns产生的结果。通常情况下，你不会想要这样的效果，除非你有意把工资排序后重新分配给数据集中顺序固定的员工，但这大概率不是你想要的。这个例子提醒我们，在使用Polars时，一定要清楚一个方法调用在表达式上和在数据框上分别会产生什么效果。

![](img/a6d232f1e997e29109fbccd482d6dbde_66.png)

![](img/a6d232f1e997e29109fbccd482d6dbde_67.png)

另外，表达式上的sort方法和数据框上的sort方法接受的参数是完全一样的。比如，我也可以把descending参数设置为True而不是False，这样salary列就会从最高工资排列到最低工资。同样地，这些员工并不会保留自己原本对应的工资，salary列里的值只是被排序后的结果，最终会覆盖原来的salary列，因为这里使用了with_columns。这一点请务必记住。

好了，以上就是Polars中按单列排序的快速介绍。通过本节课的学习，我们已经能够灵活地控制升序和降序，处理缺失值，并理解了大小写字母的排序规则。下一节课，我们将继续学习如何按多个列进行排序，敬请期待。

### 总结

![](img/a6d232f1e997e29109fbccd482d6dbde_70.png)

本节课中我们一起学习了Polars中按单个列排序的多种方式。我们首先了解了默认排序顺序是升序，以及数字、字符串、日期在升序下的具体含义；接着通过salary列、name列和start date列的示例，掌握了sort方法的基本用法。然后，我们学习了如何使用descending参数来实现降序排序，以及降序在不同数据类型下的表现。我们还探讨了缺失值在排序中的默认位置，以及如何通过nulls_last参数把缺失值放到末尾。此外，我们也搞清楚了大小写字母的排序规则：大写字母始终排在小写字母之前。最后，我们区分了在数据框上调用sort方法和在表达式上调用sort方法的不同效果，明白了后者并不会移动数据框的行顺序，而只是对某一列的值进行独立排序并覆盖原列。希望这些内容能帮助你更自信地使用Polars进行数据排序。
