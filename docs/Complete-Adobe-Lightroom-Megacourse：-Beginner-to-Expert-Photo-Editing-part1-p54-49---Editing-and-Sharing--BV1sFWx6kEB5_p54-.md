
# Adobe Lightroom 从入门到精通：54：编辑与分享 📸

![](img/b9641bfe8aacaebff61b90c1ee2957a9_1.png)

在本节课中，我们将学习如何使用 Adobe Lightroom 对一张建筑照片进行完整编辑，并最终将编辑结果分享到 Lightroom 社区。我们会从图像的裁剪和校正开始，依次调整光线、白平衡、颜色混合、色彩分级以及细节，最后制作预设并发布作品。每一步都会用大白话解释，确保初学者也能轻松跟上。

---

## 第一步：裁剪与图像校直

上一节我们介绍了基础编辑技巧，本节中我们来看看如何把这些技巧应用到实际照片上。首先需要处理的是图像的构图和平直度。

以下是裁剪与校直的具体操作步骤：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_3.png)

- 打开一张包含建筑和天空的照片，这张图片大约一半是天空，一半是建筑。
- 观察建筑物边缘，目前图像有轻微倾斜，线条不够笔直。
- 点击下方的裁剪工具，启动图像校直功能。
- 先让 Lightroom 自动尝试校直，查看自动效果是否理想。
- 如果自动校直效果不佳，手动调整旋转角度，直到建筑物的边缘与画面边框保持平行。
- 确认图像已经变得笔直，点击完成按钮。

![](img/b9641bfe8aacaebff61b90c1ee2957a9_5.png)

公式表示校直逻辑如下：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_7.png)

```text
最终图像 = 原始图像 + 旋转角度调整 + 裁剪边框修正
```

![](img/b9641bfe8aacaebff61b90c1ee2957a9_8.png)

![](img/b9641bfe8aacaebff61b90c1ee2957a9_10.png)

完成这一步之后，建筑物的垂直线条已经变得比较直了，接下来我们可以继续处理透视变形问题。

## 第二步：几何变换与透视调整

刚才我们完成了基础的图像校直，本节中我们来看看如何进一步调整建筑的几何形状，让线条更加规整。

以下是几何变换的调整方法：

- 在编辑面板中找到几何选项卡，也叫作变换选项卡。
- 点击进入后，让 Lightroom 自动识别画面中的直线并进行初步调整。
- 手动微调旋转角度，尝试不同方向，对比哪个效果更自然。
- 如果需要改变图像比例，可以拉伸宽度或高度，让建筑比例更协调。
- 垂直方向方面，可以开启受限裁剪，防止画面内容超出边界。
- 水平方向可以稍微向左移动，使建筑物位置更居中。
- 如果水平调整后图像又变得不够直，可以撤销水平操作，只保留垂直方向的修正。
- 使用 Y 轴偏移量，把建筑物移动到画面正中间一半的位置。
- 最终实现建筑和天空的完美平分，前后对比可以看到明显差异。

代码形式表示几何调整参数如下：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_12.png)

![](img/b9641bfe8aacaebff61b90c1ee2957a9_13.png)

```json
{
  "旋转": "手动微调",
  "纵向": "仅调整垂直方向",
  "横向": "向左移动后撤销",
  "缩放": "Y 轴偏移对齐",
  "效果": "建筑占据画面一半"
}
```

![](img/b9641bfe8aacaebff61b90c1ee2957a9_15.png)

![](img/b9641bfe8aacaebff61b90c1ee2957a9_17.png)

## 第三步：光线与白平衡设置

![](img/b9641bfe8aacaebff61b90c1ee2957a9_21.png)

上一节我们完成了图像的形状调整，本节中我们来看看如何让照片的亮度和色温更符合预期。

以下是光线与白平衡的调整细节：

- 检查曝光度，这张照片在白天拍摄，原始曝光已经比较合适，可以看清所有细节。
- 稍微降低对比度，避免光影过于剧烈。
- 其他光线滑块暂时不需要动，保持当前状态即可。
- 进入白平衡设置，给画面增加暖色调。
- 调整色温偏暖，再添加一点色调偏移，让整体色彩更有质感。

简单来说，光线调整的核心就是保证画面亮度适中，色温偏暖，这样后续的颜色处理才会更顺畅。

---

## 第四步：颜色混合器调整

光线设置完成后，本节中我们来看看如何使用颜色混合器来改变具体颜色的色相、饱和度和亮度。

以下是颜色混合器的调整步骤：

- 先处理蓝色通道，把天空从自然蓝色改为更偏青蓝的颜色，这种效果更有设计感。
- 调整蓝色的饱和度增加 5，同时适当提高亮度，让天空更鲜艳。
- 接下来处理建筑物颜色，建筑主要呈现黄色调。
- 将黄色改为桃色，这样建筑和天空形成更好的对比，画面更协调。
- 处理青色通道，把色调向绿色一侧移动，让窗户颜色更自然。
- 这一步是在改变窗户部分的色相，仔细观察可以看到颜色变化。
- 检查画面中是否还有红色，将红色数值调整为负 20，降低红色的存在感。
- 颜色混合器的主要调整到此完成。

颜色调整的逻辑可以用下面的代码块概括：

```text
天空颜色 = 自然蓝 + 青色偏移 + 饱和度 +5 + 亮度提升
建筑颜色 = 黄色 → 桃色
窗户颜色 = 青色 → 偏绿色
红色调整 = -20
```

颜色处理完成之后，我们可以进一步使用色彩分级来增强画面氛围。

---

## 第五步：色彩分级处理

颜色混合器调整完后，本节中我们来看看色彩分级如何为阴影、中间调和高光分别添加颜色。

以下是色彩分级的操作方法：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_23.png)

- 针对阴影部分，添加暖橙色，或者使用偏红的颜色来增强暖色感。
- 先尝试红色调整，之后可以回来继续优化。
- 进入中间调，选择暖黄色作为基础色调。
- 提高亮度，让中间调部分更明亮。
- 处理高光部分，添加一种去饱和的粉红色，也可以理解为淡红色。
- 整体色彩分级方面，不添加全局颜色，保持局部调整的灵活性。
- 回到颜色混合器，再次处理天空，让青蓝色更明显。
- 降低天空的饱和度再增加 10，达到满意的效果。

色彩分级的目的是让阴影温暖，中间调柔和，高光粉嫩，三者结合形成统一的视觉风格。

## 第六步：效果与色调曲线

![](img/b9641bfe8aacaebff61b90c1ee2957a9_27.png)

色彩分级完成后，本节中我们来看看如何使用效果面板和色调曲线来进一步提升图像质感。

![](img/b9641bfe8aacaebff61b90c1ee2957a9_29.png)

以下是效果与曲线的调整内容：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_31.png)

- 在效果面板中添加雾霾效果，营造一种淡出的复古质感。
- 增加清晰度，让边缘细节更分明。
- 设置去雾参数，让画面颜色变浅而不是变暗。
- 进入点状曲线面板，稍微提升阴影部分。
- 创建一个 S 型曲线，用来增强整体对比度。
- 调整高光部分，完成当前的 S 曲线形状。
- 回到颜色混合器，将橙色再改得更接近桃色。
- 降低亮度，让橙色调整更细腻。
- 此时整体着色效果已经比较理想。

S 曲线的作用可以简要表示为：

```text
对比度提升 = 阴影抬升 + 高光压制 + 中间调微调
```

![](img/b9641bfe8aacaebff61b90c1ee2957a9_33.png)

![](img/b9641bfe8aacaebff61b90c1ee2957a9_34.png)

完成曲线和效果调整后，我们需要检查图像的锐化和噪点情况。

## 第七步：细节锐化与降噪

![](img/b9641bfe8aacaebff61b90c1ee2957a9_36.png)

色调曲线处理完毕，本节中我们来看看如何对图像进行锐化，并检查是否存在噪点问题。

以下是细节处理的步骤：

- 放大图像，仔细查看需要锐化的区域。
- 适当增加锐化数值，让边缘更清晰。
- 检查噪点情况，这张照片噪点非常轻微，不需要特别处理。
- 如果噪点不明显，可以直接缩放回原始视图继续后续操作。

细节处理不需要过度操作，只要保持画面清晰、噪点可接受即可。

## 第八步：最终检查与保存

![](img/b9641bfe8aacaebff61b90c1ee2957a9_42.png)

所有参数调整完成后，本节中我们来看看如何进行最终检查，确保图像没有问题。

![](img/b9641bfe8aacaebff61b90c1ee2957a9_44.png)

以下是最终检查的要点：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_46.png)

- 对比修改前后的效果，颜色发生了显著变化，构图也发生了变化。
- 再次检查辅助线，确认建筑物是否正好位于画面中央。
- 如果建筑位置不够居中，再次上移建筑，直到正好位于中间位置。
- 考虑是否需要删除画面中的某些元素，比如老建筑上的瑕疵。
- 决定保留原始元素，因为这是分享个人拍摄体验，过度修复会让照片显得虚假。
- 不进行修复或不必要的删除，直接保留真实的拍摄状态。

检查完成后，图像就已经编辑完毕，可以准备导出和分享了。

![](img/b9641bfe8aacaebff61b90c1ee2957a9_48.png)

## 第九步：创建并保存预设

![](img/b9641bfe8aacaebff61b90c1ee2957a9_50.png)

图像编辑完成之后，本节中我们来看看如何将当前调整保存为预设，方便以后套用到其他照片。

![](img/b9641bfe8aacaebff61b90c1ee2957a9_52.png)

以下是创建预设的步骤：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_54.png)

- 点击右上角的云图标旁边的加号按钮，将图像上传到云端存储。
- 这样即使手机丢失，照片也不会丢失，非常适合云端备份。
- 点击右上角的三个点，选择创建预设。
- 保留所有调整选项，但不包括几何变换和光学修正，因为这些参数只适用于当前这张建筑照片。
- 将预设保存到用户预设文件夹，创建新组并命名为“建筑”。
- 在组内创建具体预设，命名为“桃色和青蓝”，这样以后一看就知道是什么效果。
- 点击完成按钮，预设就创建好了。
- 在预设库中可以看到新建的“桃色和青蓝”预设，位置在晕暗效果下方。
- 如果不需要这个预设，也可以重命名或删除。

预设创建的逻辑如下：

```text
预设内容 = 所有调整 - 几何变换 - 光学修正
预设名称 = 桃色和青蓝
保存位置 = 用户预设 > 建筑组
```

预设保存好之后，我们就可以把作品分享到 Lightroom 社区了。

## 第十步：分享作品到社区

预设创建完成后，本节中我们来看看如何将编辑后的图像分享到 Lightroom 社区，让其他人欣赏。

![](img/b9641bfe8aacaebff61b90c1ee2957a9_60.png)

以下是分享作品的具体操作：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_62.png)

![](img/b9641bfe8aacaebff61b90c1ee2957a9_64.png)

- 点击云图标旁边的分享按钮，选择分享编辑选项。
- 分享编辑不仅会发布图像，还会分享编辑过程，让别人看到你的调整步骤。
- 点击分享后会打开一个新窗口，可以给图像添加标题。
- 标题可以随意起，比如“晴朗的日子”，描述可以写“正在路过，捕捉景色”。
- 添加与图像相关的分类，这样其他人能更快找到你的作品。
- 如果有人对建筑感兴趣，给图像添加建筑分类，就能让他们看到这张照片。
- 因为照片是一栋建筑，所以选择建筑分类。
- 同时选择人物分类，因为建筑里有人居住。
- 还可以添加城市旅行、纪实等分类，表示正在记录居住在这栋建筑里的人和建筑本身。
- 只选择与图像相关的分类，不要添加无关分类，避免让社区用户感到困惑。
- 因为图像是彩色的，所以不能选择黑白分类。
- 开启允许他人保存预设的权限，这样别人可以把你的调整保存为自己的预设，预设上会标注你的名字。
- 开启位置信息，别人可以知道照片拍摄的地点和时间。
- 版权信息默认显示你的名字，也可以在个人资料中修改名字。
- 确认无误后，点击右上角的对勾提交，或者点击左上角的叉号取消。

分享流程可以简化为：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_66.png)

```text
分享动作 = 点击分享 → 填写标题 → 添加分类 → 设置权限 → 提交发布
```

提交之后，你的个人资料就在 Lightroom 社区正式上线了。

![](img/b9641bfe8aacaebff61b90c1ee2957a9_68.png)

![](img/b9641bfe8aacaebff61b90c1ee2957a9_70.png)

作品分享完成后，本节中我们来看看如何查看和管理 Lightroom 社区的个人资料以及关注列表。

以下是个人资料管理的相关内容：

![](img/b9641bfe8aacaebff61b90c1ee2957a9_76.png)

![](img/b9641bfe8aacaebff61b90c1ee2957a9_77.png)

- 分享完成后，图像会出现在你的 Lightroom 个人资料页面。
- 可以复制链接，或者分享到其他平台。
- 此时你的个人资料里只有一张独立图像。
- 进入关注列表，可以看到之前关注的账号。
- 某些账号来自其他平台，比如 Bee Hands，因为它们不在 Lightroom 社区，所以显示零条编辑。

- 关注者列表里显示的是来自其他平台的关注者，而不是 Lightroom 社区的关注者。

- 也可以通过右上角图标分享个人资料。
- 编辑个人资料时会跳转到另一个网页，需要先登录 Adobe 账号才能修改。

## 本节课总结

![](img/b9641bfe8aacaebff61b90c1ee2957a9_89.png)
