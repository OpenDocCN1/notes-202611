
# 📸 Adobe Lightroom 完全教程：37：示例 - 错误与正确编辑对比

![](img/e0f17754e88dc98e557253cbc94d065e_0.png)

在本节课中，我们将学习如何通过对比两张不同的照片，理解 Adobe Lightroom 中正确编辑与错误编辑的区别。你会看到一张看起来很糟糕的图片，以及一张经过初步改进但仍有提升空间的图片。通过这两个例子，你可以直观地认识到过度锐化、倾斜构图、曝光不足和颜色过饱和等问题对照片质量的影响。这节课的目标是帮助你建立对“正确编辑”是什么的初步感知，为后续深入学习 Lightroom 各个面板打下基础。


## 第一张有问题的图片

上一节我们介绍了 Lightroom 的基本界面和常用滑块，本节中我们来看看一个编辑失败的实际例子，了解哪些做法应该避免。

当你打开这张图片时，第一感觉就是不舒服，画面显得粗糙且不自然。这种图片不会让人感觉舒服，反而让人觉得这里面有很多问题，完全看起来不正常。

具体来看，这张图片存在以下问题：

- 图片倾斜，构图不正；
- 阴影粗糙，缺乏细节；
- 整体曝光不足，画面太暗；
- 边缘过度锐化，出现不自然的硬边。

简单来说，这就是一个乱套的局面。当你错误地使用所有编辑原则时，就会得到这样的结果。很多初学者刚打开 Lightroom 时，容易把所有滑块推到最大，或者干脆全部拉到最小，想看看效果如何。但大多数时候，这样处理过的图片虽然看起来锐利且颜色艳丽，却并不正确，也不是我们想要的效果。因此在编辑时，你要避免产生这类图片，这绝对不是我们的目标。


## 第二张较好的图片

刚才我们分析了一张有明显问题的照片，本节中我们来看看另一张相对较好的图片，找出它做得好的地方以及还能改进的地方。

这张图片看起来更柔和一些，整体比较正确。画面不再倾斜，锐度合适，高光部分得到了控制，阴影也得到了合理的曝光。不过它仍然可以做得更好。比如可以增加对比度，因为人物的脸部看起来太亮了，背景里的细节也不够突出。

你会发现，目前主体和背景的亮度差不多，这并不正确。显然，当拍摄对象位于相机前方，相机对焦于它时，对焦部分和未对焦部分之间应该存在亮度或清晰度上的差别。所以这张图片比上一张好很多，但仍然有提升空间。


## 良好编辑图片的核心原则

前面我们看过了两张对比图片，本节中我们来看看一张编辑得比较好的照片应该具备哪些核心原则。

以下是良好编辑图片的关键表现：

```
好照片 = 清晰主体 + 正确曝光 + 自然颜色 + 主体背景分离
```

具体来说，一张编辑得当的图片应该做到：

- 清晰度：你能清楚地看到人物的眼睛、头发、帽子以及其他所有特征；
- 正确曝光：图片不太暗，能够辨认出背景中的山脉、向日葵，以及主体周围的道具；
- 自然颜色：向日葵呈现自然的向日葵颜色，绿叶看起来像真正的叶子，颜色鲜艳但不过度饱和，人物面部有健康的血色，既不会像僵尸，也不会像吸血鬼；
- 天空与云朵：蓝天中带有一些云朵，颜色差异帮助我们轻松识别出云朵的形状。

当你观察这张图片时，可以迅速分辨出各个部分，而与之前那张糟糕的图片不同，后者太粗糙，让人看着不舒服，甚至难以分辨那些看起来像霓虹灯一样的花朵。在糟糕的图片中，人物脖子上的围巾颜色被破坏了，衣服和头发的细节完全丢失，而且图片还倾斜了。

但当图片曝光正确时，我们就能看到衣服和头发的细节，同时也能辨认出背景和周围的道具。这就是一张正确曝光图片应该呈现的样子。当然，它还可以更好，比如可以再稍微降低阴影，或者增加一些对比度。
