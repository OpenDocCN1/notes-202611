完整Adobe Lightroom大课：01：56 安装预设 📸


在本节课中我们将要学习如何在网上为Lightroom手机版下载预设，并把这些预设导入到应用程序里面使用。我们还会了解怎样把调整好的效果保存成自己的用户预设，并且把预设整理成不同的分组，这样以后找起来会更方便。除此之外，我们还会看看怎么把一张照片上的调整参数复制到另一张照片上，省去重复操作的麻烦。这节课的内容比较基础，会用最直白的语言把每一个步骤都讲清楚，适合刚开始接触Lightroom手机版的新朋友跟着学习。


![](img/11e1ccba43403807f6d45a6a7cfd1a93_3.png)

上一节我们介绍了Lightroom桌面版的预设安装方法，本节中我们来看看手机端该如何操作。首先你要做的事情和桌面版差不多，就是上网搜索Lightroom预设。搜索的时候要特别注明你需要的是手机版还是桌面版，因为这两个版本使用的文件格式不一样。手机版的预设通常是DNG格式，桌面版的预设通常是XMP格式。另外，下载预设的时候要注意来源安全，最好是你认识的摄影师，或者那个人在网上有良好口碑、值得信赖。如果是一些看起来不太正规的网站，就不要随便下载，否则有可能把病毒带到你的手机里面。


以下是判断预设是否适合你手机的关键检查点：

![](img/11e1ccba43403807f6d45a6a7cfd1a93_5.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_7.png)

- 网站会明确标注这个预设是适合iPhone还是适合Android
- 通常会有分别针对两种系统的不同下载链接
- 有些网站可能既没有iPhone版本也没有Android版本，这时候你需要在页面往下滚动的时候自己确认兼容性
- 只有确认和你的手机系统匹配，才能正常使用


![](img/11e1ccba43403807f6d45a6a7cfd1a93_9.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_11.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_13.png)

找到合适的预设之后，接下来我们需要把它下载到手机里，再导入Lightroom应用程序。演示过程中我们会用Chrome浏览器来搜索和下载。当你在网站上看到喜欢的预设，可以点击下载按钮，浏览器右上角的三个点菜单里会有保存图片的选项。这里要记住，DNG是一种高质量的原始图像格式，它能把预设里的所有调整细节完整地保存下来，所以从网上弄回来再保存成自己的预设非常方便。


![](img/11e1ccba43403807f6d45a6a7cfd1a93_15.png)

以下是把DNG预设导入Lightroom手机版的具体步骤：

![](img/11e1ccba43403807f6d45a6a7cfd1a93_17.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_18.png)

1. 在浏览器中把DNG文件下载到手机相册
2. 打开Lightroom，你会看到刚才导入的那张图片出现在最下方
3. 点击这张图片，你会发现每个调整图标旁边都有半圆形的标记，这说明图片里已经包含了完整的光影、颜色、效果和锐化等调整参数
4. 点击锐化选项旁边的工具栏，再点击旁边带圆圈的三个点图标
5. 选择创建预设，给它起一个和原来差不多的名字，比如叫Urban
6. 把所有设置保持默认开启状态，然后创建一个新的预设分组，比如写在线预设，这样可以把网上下载的预设和社区预设以及自己制作的预设分开管理
7. 点击对勾确认，预设就会被添加到刚才创建的在线预设分组里面


![](img/11e1ccba43403807f6d45a6a7cfd1a93_20.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_21.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_22.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_24.png)

核心格式说明可以用下面这个简单的公式来理解：

```
移动端预设格式 = DNG
桌面端预设格式 = XMP
```


预设保存好之后，我们需要看看它在不同照片上的实际效果。这时候最好找一张城市风景照片来试用，因为城市色调预设原本就是为建筑、街道、汽车这些城市元素设计的，放在这类照片上面效果会最好。如果你发现套用之后照片看起来太冷，或者颜色不太喜欢，可以点击三个点，先确认一下，然后自己手动做一些调整。比如把色温调得暖和一些，或者去掉不需要的色调分级效果，让画面变得更符合你的口味。


![](img/11e1ccba43403807f6d45a6a7cfd1a93_26.png)

以下是应用预设之后常见的手动调整项目：

- 色温：当画面显得太冷的时候，就往暖色方向调整
- 色调分级：如果画面出现了不喜欢的黑白加棕色调效果，可以把它去掉
- 红色和橙色：当照片里出现太显眼的橙色线条时，可以适当降低红色和橙色的饱和度


![](img/11e1ccba43403807f6d45a6a7cfd1a93_28.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_30.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_32.png)

有时候预设直接套用并不是完美的，我们需要做一些后期修正才能让照片看起来更好。比如在某张照片上套用城市预设之后，可能会出现一些奇怪的橙色线条，这时候可以把红色稍微降低一点，再把一部分红色调回来，让颜色看起来更自然。你还可以尝试添加一点色调分级，选用暖色调来营造出日出或者日落的氛围，不过具体要不要加，要根据照片里的光线和主题来决定。


![](img/11e1ccba43403807f6d45a6a7cfd1a93_34.png)

除了直接调用已经保存好的预设，Lightroom手机版还提供了另一种快速把效果应用到其他照片上的方法。就是复制设置功能。你可以在已经套用了预设的那张照片上面点击上方的三个点，然后选择复制设置。在复制的时候可以把所有项目都选上，但建议不要复制地理位置和光学矫正这两项。完成复制之后，剪贴板里就会保存那些设置，你可以打开另一张任意照片，同样点击三个点，选择粘贴设置，这样原图上的所有调整参数就会被应用到新照片上面。


![](img/11e1ccba43403807f6d45a6a7cfd1a93_36.png)

![](img/11e1ccba43403807f6d45a6a7cfd1a93_38.png)

以下是使用复制设置功能时需要注意的选项：

![](img/11e1ccba43403807f6d45a6a7cfd1a93_40.png)

- 可以先全部选中，再根据需要去掉不想要的项目
- 建议把地理位置和光学矫正这两项取消勾选
- 如果你不希望把裁剪也复制过去，记得在工具选项里把裁剪关掉
- 粘贴完成后，你可以左右拖动图片查看之前和之后的效果对比


本节课中我们一起学习了如何在网上寻找并下载适合手机端的Lightroom预设，如何把DNG文件导入Lightroom并保存成自己的预设分组，如何在城市照片上试用预设并做手动微调，以及如何把一张照片上的调整设置复制到其他照片上。下一节课我们将学习如何使用这些预设和设置来进行批量编辑。
