
# 📘 数据分析与Polars和Python：第23讲：字典

在本节课中，我们将要学习Python中的下一个内置对象——字典（dictionary）。字典是Python中用于表示“关联关系”的容器，它和列表一样常见，也是数据分析中经常打交道的结构。我们会从字典的基本概念讲起，搞清楚它和列表有什么不同；然后通过一个餐厅菜单的例子来创建字典、添加键值对、获取长度、按键访问值、修改和删除键值对；最后我们还会学习如何用`in`和`not in`检查字典中是否存在某个键或值。学完这节课，你将能够在程序中用字典来模拟现实世界里各种“一一对应”的关系。

## 什么是字典

在开始动手写代码之前，先要理解字典的本质。我们之前学过的列表（list）解决的是“按顺序存储”的问题，而字典要解决的是一个互补的问题：关联（association）。所谓关联，就是把两个值连接、映射或者链接在一起。字典对象在Python语言中的存在意义，正是帮助我们模拟这种“在两个值之间创建连接”的现实世界想法。

字典是一种可变（mutable）且无序（unordered）的键值对集合。在这里，“可变”意味着字典在创建之后可以继续变化，我们能够随时增加、删除或覆盖数据；“无序”则意味着字典内部没有位置顺序，你不应当假设哪个键值对在前、哪个在后。以下就是字典的几个关键特点：

- 字典是可变的，你可以修改它的内容。
- 字典是无序的，不要依赖顺序来操作。
- 字典存储的是键值对，一个键对应一个值。
- 字典中的键必须唯一，值却可以重复。

为什么键必须唯一呢？因为键是对应值的唯一标识符。如果同一个键出现两次，程序就不知道该取哪个值。相反，值是可以重复的，多个键共享同一个值完全合法。要注意，键和值是一对不可分割的组合：键不能脱离值而存在，值也不能脱离键而存在，它们总是作为一组关联出现。

字典可以用于很多现实中的对应关系。例如，字典可以把一个人的名字和电子邮箱地址连接起来，把一个国家和它的首都连接起来，或者把一本书的书名和作者连接起来。说到底，字典的价值不在顺序，而在关联：它能在两个值之间建立桥梁或链接。同时，字典也是一个容器，可以保存多个键值对，也就是多组“一个值关联另一个值”的关系。

## 创建字典：餐厅菜单的例子

理解了概念之后，我们来看一个现实中的应用：用Python字典模拟餐厅菜单。餐厅菜单非常适合用字典建模，因为菜单天生就是“菜名”和“价格”的关联表。我们可以把键想象成菜单上的菜品，把值想象成对应的价格；每个菜品都有一条要连接的价格。菜单上哪个菜品排在前面并不重要，重要的是菜名和价格之间的对应关系。

首先，我们来声明一个`menu`变量。创建字典要使用一对花括号`{}`。回想一下，列表使用的是一对方括号`[]`，而字典使用的是花括号`{}`，两者正好形成互补。和空列表、空字符串一样，我们也可以创建空字典，它包含零个键值对。

接下来，我们往字典里添加第一个键值对。为了可读性，通常我们会换行书写，这一步不是必须的，但能让结构更清晰。首先写出键，也就是唯一标识符，这里我们用一个字符串来表示菜单项，比如“菲力牛排”（filet mignon）。字典不能只存一个键而缺少值，所以我们需要在键后面加一个冒号，这是语法上必须的；冒号后可以跟一个空格，然后写出对应的值。我们假设菲力牛排的价格是29.99。写成代码就是：

```python
menu = {
    "filet mignon": 29.99
}
```

在这个例子中，键是字符串，值是浮点数。不过字典并不限制必须这样组合，键和值都可以是任意类型。比如，值也可以是一个布尔值，用来表示这道菜是否是热菜。现在，最重要的地方在于：我们有两个对象，并且在字典中为它们建立了一次关联。这就是一个键值对，也就是从键`"filet mignon"`到值`29.99`的一个映射。

如果要添加多个键值对，我们需要在每对之间加上逗号，然后通常换行以保持可读性。我们继续添加“Big Mac”（巨无霸），价格是3.99。这里要再次强调：键必须唯一，因为键要作为值的标识符。虽然Python技术上允许我们写入重复的键，但最终有效的是最后一次出现的条目，所以一个字典里只能有一个`"filet mignon"`。这个规则对所有键都适用。我们接着添加“pizza”（披萨），价格为3.99；再添加“salmon”（三文鱼），价格为29.99。完整代码如下：

```python
menu = {
    "filet mignon": 29.99,
    "Big Mac": 3.99,
    "pizza": 3.99,
    "salmon": 29.99
}
```

注意，键必须唯一，但值不要求唯一。每个菜品在菜单上只出现一次，但它们完全可以使用相同的价格。比如这里的3.99和29.99都出现了两次，这没有任何问题。

执行上面的单元格之后，我们就得到了`menu`字典。有时候Python的交互环境会把字典格式化成一行显示，这是完全正常的。接下来可以输出`menu`变量，看到字典的完整内容。输出结果会包含所有键以及它们对应的值。有时候Python会用单引号来显示字符串，这与双引号并没有技术上的区别，只是输出时的视觉表现不同。

## 获取字典的长度

拿到字典之后，我们自然想知道它有多大。Python的内置函数`len`同样适用于字典，它返回的是字典中键值对的数量。换句话说，`len`统计的是关联的个数，而不是字典中所有对象的个数。在我们这个例子中，字典里有4个键和4个值，总共8个对象，但键值对只有4组，所以`len(menu)`的结果是4：

```python
len(menu)  # 4
```

## 通过键访问字典中的值

知道长度之后，我们来解决一个更实际的问题：怎样从字典中取出某个值？在列表里，我们依靠索引位置来提取元素，因为列表有顺序。而字典是无序的，所以不能按位置取值，只能通过键来定位。访问语法和列表很像，也是使用方括号，只不过里面放的是我们要查找的键。比如想知道巨无霸的价格，只要写成`menu["Big Mac"]`，Python就会返回对应的值3.99；想知道三文鱼的价格，就写`menu["salmon"]`，得到29.99：

![](img/4b812c1de1193830ff00d64c0c143dd9_4.png)

```python
menu["Big Mac"]  # 3.99
menu["salmon"]   # 29.99
```

![](img/4b812c1de1193830ff00d64c0c143dd9_5.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_6.png)

如果你在列表中给了不存在的索引，会得到`IndexError`；类似地，如果你在字典中给了不存在的键，比如`menu["tuna"]`，Python会抛出`KeyError`，因为字典里没有`"tuna"`这个键，自然也没有对应的值可以提取。此外，键的匹配区分大小写。比如，小写的`"salmon"`并不存在于字典中，因为真正的键是首字母大写的`"Salmon"`，所以访问小写键会得到`KeyError`。这一点在实际编码时要格外留意。

## 修改字典：添加与覆盖键值对

字典创建之后并不是一成不变的，我们可以随需求修改它。当前`menu`字典里没有`"burrito"`这个键，所以任何直接访问`"burrito"`的操作都会引发`KeyError`。要想为字典添加新的键值对，语法很简单：先写字典变量名，接一对方括号，在方括号里写上新的键，然后写等号，最后写对应的值。例如，我们给墨西哥卷饼定价13.99：

![](img/4b812c1de1193830ff00d64c0c143dd9_8.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_9.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_10.png)

```python
menu["burrito"] = 13.99
```

![](img/4b812c1de1193830ff00d64c0c143dd9_11.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_12.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_14.png)

执行这行代码后，单元格下方通常不会显示任何内容，但字典本身已经发生了变化。此时再看`menu`，你会发现它已经有5个键值对：原来的4组加上新增的`"burrito"`。为了验证，可以再次调用`len(menu)`，现在的长度是5。

不过要小心：这种赋值操作并不一定只是“新增”，它也有可能覆盖已有的键值对。刚才`"burrito"`不存在，所以是新增；但如果我们选择的是`"Big Mac"`这种已经存在的键，并给它赋值为5.99，那么由于每个键只能出现一次，Python会把原来的键值对覆盖掉。执行之后，`"Big Mac"`键对应的值就会变成5.99，原来的3.99就被替换了。这就是字典中新增和覆盖键值对的方法。

## 从字典中删除键值对

![](img/4b812c1de1193830ff00d64c0c143dd9_16.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_17.png)

既然可以添加和覆盖，自然也可以删除。删除键值对时，需要指定要删除的键，涉及的方法是`pop`。回忆一下，列表的`pop`方法会移除列表中的最后一个元素；而字典的`pop`方法同样是移除键值对，但它要求传入一个参数——你要删除的键。例如，我们想删除`"filet mignon"`：

![](img/4b812c1de1193830ff00d64c0c143dd9_18.png)

```python
menu.pop("filet mignon")
```

![](img/4b812c1de1193830ff00d64c0c143dd9_20.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_21.png)

前面说过，键和值是一对整体，不能分离，所以这个操作会移除完整的键值对。`pop`方法会把被删除的值作为返回值返回，同时字典本身也会发生变化。执行后再输出`menu`，你会发现字典现在只剩下4个键值对，因为`"filet mignon"`已经被删掉了。

## 使用 in 和 not in 检查成员资格

我们还需要经常判断某个键或值是否存在。前面学习字符串和列表时，已经用过`in`和`not in`关键字；字典也可以使用它们。这里要特别注意：默认情况下，`in`是在字典的“键”中搜索，而不是在值中搜索。例如，`"Big Mac" in menu`会返回`True`，因为`"Big Mac"`是一个键；但`5.99 in menu`会返回`False`，因为虽然字典的值里确实存在5.99，但没有一个键是5.99。

![](img/4b812c1de1193830ff00d64c0c143dd9_23.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_24.png)

如果你想检查某个值是否存在于字典的所有值中，就需要调用字典的`values()`方法，拿到所有值的集合，然后再用`in`在这个集合里查找：

![](img/4b812c1de1193830ff00d64c0c143dd9_26.png)

```python
"Big Mac" in menu        # True，因为它是键
5.99 in menu             # False，因为5.99是值而不是键
5.99 in menu.values()    # True，因为值里确实有5.99
```

在第二个例子中，`menu.values()`会收集字典中的所有值，比如3.99、5.99、13.99、29.99等等，然后`in`再去查找5.99是否存在。所以，默认`in`检查键，如果要检查值，必须和`values()`方法配合。

类似地，`not in`也可以检查某个键或值是否不存在。例如，`"lasagna" not in menu`会返回`True`，因为四个键值对中没有任何键是`"lasagna"`；而`"salmon" not in menu`会返回`False`，因为`"salmon"`这个键是存在的。如果希望检查某个值是否不在字典的值之中，仍然需要借助`values()`方法。比如，我们可以问问4.99是不是不在我们的价格表里：

![](img/4b812c1de1193830ff00d64c0c143dd9_28.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_29.png)

```python
"lasagna" not in menu        # True，没有这个键
"salmon" not in menu         # False，这个键存在
4.99 not in menu.values()    # True，值里没有4.99
```

![](img/4b812c1de1193830ff00d64c0c143dd9_30.png)

## 总结

本节课中，我们一起学习了Python字典的基础知识。我们首先理解了字典是一种可变、无序的键值对集合，并记住了“键必须唯一、值可以重复”的规则。接着，我们通过餐厅菜单的例子，学习了如何用花括号创建字典，如何逐步添加多个键值对，以及如何使用`len`函数获取字典长度。然后，我们学习了如何借助方括号和键来访问值，也知道了访问不存在的键会触发`KeyError`。接下来，我们讨论了如何利用赋值语法新增或覆盖键值对，以及如何用`pop`方法删除完整的键值对。最后，我们掌握了`in`和`not in`在字典中的用法，并区分了默认检查键、通过`values()`方法检查值这两种情况。

![](img/4b812c1de1193830ff00d64c0c143dd9_32.png)

![](img/4b812c1de1193830ff00d64c0c143dd9_33.png)

总的来说，字典的核心作用是关联，它用来在键和值之间建立映射、桥梁或链接。在我们的示例中，键是字符串，值是浮点数，但实际上键和值可以是各种不同的数据类型。如果你需要保持数据的顺序，应该选择列表；如果你要解决的是关联问题，字典就是最合适的工具。
