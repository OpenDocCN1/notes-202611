
道德黑客完整课程：第36-37节：使用AndroRat获取安卓设备控制权 📱


在本节课中，我们将学习如何使用AndroRat工具远程控制安卓设备。AndroRat是一款客户端-服务器应用程序，专门用于获取安卓系统的远程控制权并收集设备信息。我们将逐步讲解从下载工具、安装依赖、生成后门文件，到在目标设备上安装并建立连接的完整过程。此外，我们还会介绍该工具的主要功能，并提醒你仅在合法授权的测试环境中使用。


![](img/516c080d40a97347144ae35ea1313546_1.png)

## 一、什么是AndroRat 🔍

上一节我们介绍了基本的渗透测试概念，本节中我们来看看AndroRat是一款什么样的工具。

AndroRat是一款专门用于远程控制安卓系统的工具。它的核心作用是让你远程掌控安卓设备，并从中收集各种信息。你可以把它理解为一种远程管理程序，只不过它被设计用于安全测试场景。

这种工具的工作原理基于客户端-服务器架构。公式如下：

```
控制关系 = 攻击者机器（服务端） ↔ 目标安卓设备（客户端）
```

客户端使用Java语言开发，运行在安卓设备上；服务端使用Python语言开发，运行在攻击者的Kali Linux系统上。这意味着你需要先在自己的机器上启动服务端，然后将客户端程序安装到目标安卓设备上，两者建立连接后，你就可以通过服务端发送指令来控制目标设备了。

在GitHub上，这个项目的创建者是Kerma 9874。你可以访问相关页面查看源代码和更多说明。


## 二、AndroRat的功能特点 🎯

在了解基本架构之后，本节中我们来看看这个工具具体能做什么。

AndroRat提供了一系列远程控制功能，以下是主要特点：
- 摄像头控制：可以获取安卓设备前置和后置摄像头的快照，并直接将图片发送到你的系统
- 音频录制：可以录制音频文件并传输到你的Kali Linux系统
- 视频拍摄：可以通过两个摄像头拍摄视频，并将视频发送到你的系统
- 通信记录：可以浏览通话记录和短信内容
- 设备信息：可以获取当前位置、SIM卡详情、IP地址和MAC地址等设备信息
- 持久化后门：声称是轻量级APK，可在后台24小时运行，并且设备启动时自动运行
- 隐藏图标：声称安装后图标不可见（实际使用中可能仍能找到图标）

需要注意的是，官方声称该工具能完全绕过任何防病毒扫描器，并且安装后图标不可见，但实际效果可能因设备和防病毒软件而异，不一定完全准确。


## 三、下载AndroRat工具 💾

在了解功能之后，本节中我们来看看如何下载这个工具。

你需要打开Firefox浏览器，搜索GitHub，找到AndroRat的项目页面。项目的链接和创建者信息都在页面上，你可以点击查看创建者的个人主页。

软件下载链接也在页面上提供。你可以直接复制这个链接，准备在终端中使用。你也可以将生成的文件通过互联网发送给目标设备，例如使用隧道工具或直接托管在Web服务器上。

![](img/516c080d40a97347144ae35ea1313546_3.png)

![](img/516c080d40a97347144ae35ea1313546_5.png)

在Kali Linux的根终端中，执行以下命令下载源代码：

![](img/516c080d40a97347144ae35ea1313546_7.png)

```bash
git clone https://github.com/Kerma9874/androRAT.git
```

下载完成后，进入项目目录并查看所有文件：

```bash
cd androRAT
ls
```

![](img/516c080d40a97347144ae35ea1313546_9.png)

![](img/516c080d40a97347144ae35ea1313546_11.png)

你会看到目录中包含多种不同类型的文件，这些文件构成了AndroRat的完整工具集。


## 四、安装依赖项 📦

![](img/516c080d40a97347144ae35ea1313546_13.png)

![](img/516c080d40a97347144ae35ea1313546_15.png)

在下载工具之后，本节中我们来看看如何安装运行所需的依赖。

![](img/516c080d40a97347144ae35ea1313546_17.png)

![](img/516c080d40a97347144ae35ea1313546_19.png)

AndroRat的服务端需要一些Python依赖包才能正常工作。你需要在项目目录下执行以下命令来安装：

```bash
pip install -r requirements.txt
```

如果安装过程中出现“无法找到匹配的分发版”之类的错误，可能需要先更新你的Linux系统：

```bash
apt-get update
```

或者安装缺失的Python文件。如果第一次安装失败，可以重新尝试，通常会有少量错误但不影响后续步骤。

![](img/516c080d40a97347144ae35ea1313546_21.png)

依赖安装完成后，你就可以开始生成自己的后门文件了。


## 五、生成APK后门文件 🔧

![](img/516c080d40a97347144ae35ea1313546_23.png)

在安装依赖之后，本节中我们来看看如何制作安卓后门程序。

你需要运行一个命令来生成APK文件，这个APK就是后门程序，安装到目标设备后会建立与你的服务端的连接。

生成APK的命令示例：

![](img/516c080d40a97347144ae35ea1313546_25.png)

![](img/516c080d40a97347144ae35ea1313546_27.png)

```bash
python androRAT.py -o system_update.apk
```

你可以为APK文件起任何名字，比如system_update.apk、android_info.apk、contacts.apk或者system_info_activity.apk。文件名越像正常应用，越不容易引起怀疑。

生成完成后，使用以下命令查看生成的文件：

![](img/516c080d40a97347144ae35ea1313546_29.png)

```bash
ls
ls -lt
```

![](img/516c080d40a97347144ae35ea1313546_31.png)

![](img/516c080d40a97347144ae35ea1313546_33.png)

你会看到系统更新.apk文件位于root/AndroidRa目录下，并且具有根权限。


## 六、启动Apache服务器 🌐

![](img/516c080d40a97347144ae35ea1313546_35.png)

![](img/516c080d40a97347144ae35ea1313546_37.png)

在生成APK文件之后，本节中我们来看看如何把文件放到Web服务器上，方便目标设备下载。

你需要启动Apache服务器，并将生成的APK文件复制到Web根目录，通常是/var/www/html。这样目标设备就可以通过浏览器访问你的IP地址来下载文件。

![](img/516c080d40a97347144ae35ea1313546_39.png)

启动Apache服务器的命令示例：

![](img/516c080d40a97347144ae35ea1313546_41.png)

```bash
service apache2 start
```

![](img/516c080d40a97347144ae35ea1313546_43.png)

启动后，检查服务状态：

```bash
service apache2 status
```

确认服务器运行正常后，将APK文件复制到Web目录：

![](img/516c080d40a97347144ae35ea1313546_45.png)

```bash
cp system_update.apk /var/www/html/
```

此时，你的Apache服务器正在等待连接，目标设备可以通过浏览器访问你的IP地址并下载APK文件。


## 七、在目标设备上安装APK 📲

![](img/516c080d40a97347144ae35ea1313546_47.png)

在启动服务器之后，本节中我们来看看如何在目标安卓设备上下载并安装这个文件。

![](img/516c080d40a97347144ae35ea1313546_49.png)

在目标安卓设备上，打开Google Chrome或任何浏览器，访问你的IP地址加上APK文件名。例如：

```
192.168.0.109/system_update.apk
```

访问后，APK文件会自动开始下载。文件大小大约2.22MB，下载时间可能需要45秒左右，具体取决于网络速度。

![](img/516c080d40a97347144ae35ea1313546_51.png)

下载完成后，点击文件进行安装。安装过程中可能会出现提示，比如“Google服务框架”或“此应用不是为旧版本构建”的警告，点击打开并授予所需权限即可。

安装完成后，你可能在设备桌面上看不到这个应用图标，这符合AndroRat声称的“隐藏图标”特性，但实际表现因设备而异。


## 八、建立连接并控制设备 🔗

在安装完成之后，本节中我们来看看如何建立会话并远程控制目标设备。

当目标设备上安装并运行了APK后，你的Kali Linux终端会显示“等待连接”，一旦设备上线，你就成功建立了会话。

![](img/516c080d40a97347144ae35ea1313546_53.png)

输入以下命令查看所有可用指令：

![](img/516c080d40a97347144ae35ea1313546_55.png)

```bash
help
```

常用控制命令包括：
- cam list：列出设备上的所有摄像头
- 通过摄像头编号拍照或录制视频
- 录制音频文件
- 浏览通话记录和短信
- 获取设备信息，如设备型号（例如小米平板）
- 获取位置、SIM卡详情、IP和MAC地址

例如，使用设备信息命令可以看到目标是一台小米平板，这是随机临时平板，测试完成后建议重置设备。

![](img/516c080d40a97347144ae35ea1313546_57.png)

结束会话时，输入以下命令：

![](img/516c080d40a97347144ae35ea1313546_58.png)

```bash
EXIT
```

这将终止当前连接，会话在目标平板上结束。
