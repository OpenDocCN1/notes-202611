
# 🍔 Adobe Lightroom 食物摄影后期编辑：064：博主风格汉堡照片编辑

![](img/a02fc0e73d5ad00fd42bd9c596630dce_1.png)

在本节课中我们将要学习如何用 Adobe Lightroom 把普通的食物照片编辑成博主风格。博主风格的照片在社交媒体上非常常见，尤其是 Instagram 和 Pinterest 上，你看到的那些汉堡、披萨或甜点照片，通常色彩鲜艳、对比度较高，背景看起来很自然，不像工作室拍摄那样刻意。本节课我们会以一张汉堡照片为例，一步步讲解如何在 Lightroom 里调出这种风格。即使你之前没有做过食物后期编辑，也能跟着步骤慢慢学会。


## 博主风格和普通食物摄影的区别

博主风格和传统食物摄影有明显区别。传统食物摄影往往追求工作室效果，背景干净整洁，会用薯条或其他道具来平衡构图，目的是让食物看起来更诱人，更像商业广告。而博主风格更偏向自然，不刻意推销产品，而是想展示博主吃饭时的真实体验。背景可以是自然环境，食物包装也可以保留，不需要刻意去除。这种风格的核心在于自然感，而不是完美的商业拍摄效果。


## 素材来源和预设问题

这类博主照片在 Instagram、Pinterest、YouTube 等社交媒体平台都能找到。很多博主会制作自己的预设出售或分享，但有时候很难获得，价格也可能较高。因此，了解如何利用已有的 Lightroom 知识自己调出同样的效果，会更实用且节省成本。


## 第一步：调整基础色调

首先我们从基础色调开始调整。博主风格的照片通常对比度很强，阴影部分会被压暗，这正是它区别于普通食物摄影的地方。

以下是基础色调调整的具体步骤：
- 使用去雾功能，把照片里的一些细节调出来，暂时不必担心照片偏黄，后面可以用自然饱和度和色相饱和度明度面板修正。
- 增加对比度，这时候你会发现阴影更深，背景也更清晰可见。
- 调整高光，把高光调高。
- 减少阴影，让暗部更暗。
- 略微增加白色，减少黑色。
- 如果照片整体偏暗，小幅增加曝光，使画面更平衡。
- 使用色温滑块给照片降温，因为目前画面偏黄，调到负数会让颜色更清晰。


基础色调调整可以用下面的代码来理解：
```
Dehaze（去雾）：提升细节
Contrast（对比度）：提升
Highlights（高光）：提升
Shadows（阴影）：降低
Whites（白色）：略微提升
Blacks（黑色）：降低
Temperature（色温）：负值，偏冷
```


## 第二步：处理细节和整体色彩

接下来处理细节和整体色彩。首先增加清晰度和纹理，让食物边缘更锐利。然后在自然饱和度面板把饱和度调高，因为照片里的生菜和西红柿看起来有点苍白。但普通饱和度不要调太高，否则颜色会过于刺眼，这时候可以适当降低饱和度。最后再稍微增加一点曝光，整体效果会好很多。完成这些之后，光线和整体画面风格就基本定下来了。


## 第三步：使用 HSL 面板修正颜色

然后进入 HSL 面板来修正具体颜色。HSL 代表色相、饱和度、明度，分别对应颜色本身、颜色的浓淡和颜色的亮暗。

以下是 HSL 面板里需要调整的颜色：
- 橙色：不要改变色相，因为橙色是汉堡包和纸张的原色。只需稍微降低饱和度，同时调整橙色的明度，把它调暗一点。
- 红色：把红色颜色调出来，让汉堡看起来更有食欲。
- 绿色：照片里的绿色看起来有点苍白，可以把绿色明度调高，让它更亮，再把色相向右移动，变成更鲜艳的绿色。
- 紫色：目前看起来不错，不需要调整。
- 蓝色：蓝色有点干扰画面，可以降低蓝色的饱和度，让整体更协调。


HSL 调整的逻辑可以用下面的公式表示：
```
HSL 调整 = 色相（H） + 饱和度（S） + 明度（L）
```


## 第四步：使用色调曲线提升光影

接下来使用色调曲线来进一步提升光影表现。色调曲线可以让我们更精确地控制暗部和亮部。

以下是色调曲线的调整思路：
- 先整体修改图片。
- 调整阴影，把阴影降低，让暗部更暗。
- 高光保持较亮，因为面包和背景上有很多高光，我们想要保留这些细节。
- 再增加对比度，形成类似增强的 S 曲线，哪怕曲线看起来有点波浪形也没关系。
- 可以再微调对比度，稍微提升一下阴影，让画面不至于太生硬。
- 如果觉得画面太粗糙，也可以增加一点清晰度。


## 第五步：使用颜色分级统一色调

色彩调整完成后，进入颜色分级面板。因为目前照片还是偏黄，我们可以选择一个相反的颜色来中和。先在中间调尝试，如果不满意就重置，改用全局颜色。这样可以给画面整体降温，营造出一种独特的背景氛围。饱和度可以保持在 33 左右，不要调得太高，否则效果会不好。


## 第六步：检查细节和镜头校正

然后查看细节面板。放大图片检查，照片已经比较锐利，噪点也不明显，所以不需要再做额外的锐化或降噪。接着进入镜头校正，可以给照片添加鱼眼效果，让画面更有特色。同时检查是否有色差，如果发现有彩色边缘，可以放大图片查看彩色部分，通常不需要处理。按 J 键可以检查是否有曝光错误，目前没有问题。蓝色部分稍微有点不成比例，但这正是我们想要的风格。


## 第七步：变换面板和主要颜色校正

接下来看变换面板。由于照片里有很多圆形元素，形状之间没有和谐关系，所以变换面板在这里用处不大，除非你想改变透视。不过目前这个拍摄角度已经很好，不需要强行调整。

然后处理主要颜色校正，重点调整红色原色，因为图片里有很多橙色和红色，可以把色相向右移动，让颜色偏向橙色而不是亮红色，再稍微调整饱和度，让效果更真实。绿色和蓝色不需要太多处理。最后再增加一点去雾，去除残余的雾气感。完成这些后，照片就算编辑完成了。


## 第八步：查看前后对比和参考示例

现在可以对比修图前后的效果。照片边缘更锐利，颜色更饱和，整体偏哑光，阴影保持较暗，背景看起来自然，并且添加了鱼眼效果。如果你对这种风格不太熟悉，可以在网上搜一些前后对比的例子，看看这种编辑风格在互联网上很流行。虽然不一定要追求这种高饱和高锐利的效果，也可以选择复古风格或低饱和度风格，但了解多种风格会给你更多选择。很多博主在卖预设，但现在你已经学会自己调色，不需要再购买那些预设。


本节课中我们一起学习了如何用 Adobe Lightroom 调出博主风格的食物照片。我们从基础色调入手，调整了去雾、对比度、高光阴影、曝光和色温；接着用 HSL 面板和色调曲线细化了橙色、红色、绿色和蓝色的表现；最后通过颜色分级、镜头校正和主要颜色校正，完成了一张带有鱼眼效果的博主风格汉堡照片。希望你喜欢这节课，我们下节课再见。
