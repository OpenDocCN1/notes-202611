
# 📘 使用 Polars 和 Python 进行数据分析：第43节：从 CSV 读取 DataFrame

在本节课中，我们将学习如何用 Polars 从 CSV 文件读取数据，并生成一个 DataFrame，同时把 DataFrame 上常用的一些方法和属性一起复习一遍。上一节课程中，我们已经介绍了 Polars 顶层的 Read CSV 函数，这一节一开始，我们先快速回顾一下这个函数，然后看看读取出来的数据长什么样，再认识几个非常实用的属性和方法。

## 📂 读取 CSV 文件

![](img/758f53dc6077b8cb2215235a3048b918_1.png)

Read CSV 函数做的事情，就是把一个 CSV 文本文件导入成一个等价的 Polars DataFrame。我们可以直接在代码里写成 `pl.read_csv(...)`，其中第一个参数就是文件名，或者文件所在的完整路径。本节里我们主要会使用的数据集叫做 `Employees.csv`，这是一个虚构公司里 1000 名员工的信息列表，接下来的很多操作都会围绕这个数据来展开。

```python
import polars as pl

employees = pl.read_csv("Employees.csv")
```

为了让你对这个数据集有个直观印象，我们把读取出来的结果保存到一个叫 `employees` 的变量里，然后把它输出出来。你可以看到，和之前处理 Series 时一样，Polars 并不会把整个 DataFrame 都打印到屏幕上，因为它不想把画面一下子塞满。它默认会先显示前五行，接着出现一行省略号，最后再显示整个 DataFrame 末尾的五行。这种展示方式能让你快速对数据有一个初步印象。

![](img/758f53dc6077b8cb2215235a3048b918_3.png)

具体来说，这个数据集中每一名员工都有下面这些信息：

![](img/758f53dc6077b8cb2215235a3048b918_4.png)

- `name`：员工姓名。
- `department`：员工所属的部门。
- `email`：员工的邮箱。
- `annual_salary`：员工的年薪，这是一个整数。
- `years_at_company`：员工在公司工作的年数，这也是一个整数。
- `start_date`：员工入职的日期。严格来说，它应该是一个日期时间类型，但默认情况下，Polars 会把这个字段作为普通文本字符串导入。我们稍后会讨论如何修改这一点。

## 🛠️ DataFrame 的常用方法

上一节我们在 Series 上介绍的很多方法和属性，在 DataFrame 上同样可以使用，而且语法完全一样。我们只需要写出对象本身，或者指向这个对象的变量，然后带上点号、方法名、一对括号，有时候还需要传入一些参数来调整方法的具体行为。下面我们就来看几个最常见的例子。

先说 `head` 和 `tail` 这两个熟悉的方法，它们分别用来从 DataFrame 的开头或末尾返回指定数量的行。比如，我可以直接对 `employees` 这个 DataFrame 调用 `head` 方法：

```python
employees.head()
```

![](img/758f53dc6077b8cb2215235a3048b918_6.png)

![](img/758f53dc6077b8cb2215235a3048b918_7.png)

![](img/758f53dc6077b8cb2215235a3048b918_8.png)

![](img/758f53dc6077b8cb2215235a3048b918_9.png)

默认情况下，`head` 会打印出前五行。这里有一个需要特别注意的区别：DataFrame 的 `head` 默认显示前五行，而 Series 的 `head` 默认显示前 10 行。不过，我可以通过自定义 `n` 参数来改变显示的行数。例如，我可以让 `head` 显示出前七行：

![](img/758f53dc6077b8cb2215235a3048b918_10.png)

```python
employees.head(7)
```

另外，Polars 里还有一个互补的 `limit` 方法，它其实就是 `head` 的别名，底层的实现完全一样，只是换了一个名字而已。比如我想预览前四行，就可以这样写：

![](img/758f53dc6077b8cb2215235a3048b918_12.png)

![](img/758f53dc6077b8cb2215235a3048b918_13.png)

```python
employees.limit(4)
```

![](img/758f53dc6077b8cb2215235a3048b918_14.png)

当然，有开头就有结尾。`tail` 方法可以从 DataFrame 的末尾返回指定数量的行。如果我想拿到 `employees` 数据里的最后九行，只需要给 `tail` 传入一个参数 `9`，这样就能得到最后九行数据：

```python
employees.tail(9)
```

## 🧩 方法与属性的区别

在继续看更多例子之前，我们需要把方法和属性这两个概念彻底分清。方法是一个我们向对象下达的命令，也就是我们可以要求对象去执行的一个动作。通常情况下，方法会涉及某种计算，或者说某种开销比较大的操作。相比之下，属性只是存在于对象上的一段数据，它是关于这个对象的一个细节、一个特征，或者说一个对象可以直接告诉我们的关于它自身的事实。

```python
方法 = 让对象执行的动作（通常要计算）
属性 = 对象身上保存的事实（直接读取）
```

两者在使用上有非常明显的区别：方法需要带括号，而属性只需要一个点和属性名，不需要加括号。下面就来介绍几个 DataFrame 上很常用的属性。

## 🏷️ DataFrame 的常用属性

首先是最直观的 `columns` 属性。我可以对 `employees` 这个 DataFrame 加上一个点，然后写上属性名 `columns`，这样就能得到一个 Python 列表，里面包含了 DataFrame 中所有列的名字：

```python
employees.columns
# ['name', 'department', 'email', 'annual_salary', 'years_at_company', 'start_date']
```

接下来还有一个属性叫 `dtypes`，它是 data types 的缩写。这个属性会给我们返回一个列表，列表里按照顺序保存了所有列的数据类型。如果我们把这里面的值按照索引位置去逐一对齐，就可以看到，`name` 列存的是字符串，`department` 列同样存的是字符串，而 `salary` 列保存的则是整数：

```python
employees.dtypes
```

![](img/758f53dc6077b8cb2215235a3048b918_22.png)

![](img/758f53dc6077b8cb2215235a3048b918_23.png)

![](img/758f53dc6077b8cb2215235a3048b918_24.png)

不过，`columns` 和 `dtypes` 是两个相互独立的属性，每次都要把这两份信息手动对应起来，多少会让人觉得有点麻烦，也比较容易搞混。幸好，Polars 还提供了一个 `schema` 属性，它可以只用一次属性访问，就同时告诉你列名和对应的数据类型。

如果你不太熟悉 schema 这个词，可以把它理解为一个计划、大纲或模型的表现形式。换句话说，当我们访问 `schema` 时，我们实际上是在请求一个关于 DataFrame 内部结构的表示或大纲。例如，我可以直接这样写：

```python
employees.schema
```

这里返回的是一个 `Schema` 对象，它是 Polars 库中一种比较特殊的对象。你会发现它的输出有点特别，整体上是由一些类似于元组的结构组成的，每个结构里都会告诉你一个列的列名，以及这个列关联的数据类型。比如，`name` 列存储的是字符串类型的值，而 `years_at_company` 列存储的是整数类型的值，更准确一点说，是 64 位整数。

## 📐 获取行数与列数

![](img/758f53dc6077b8cb2215235a3048b918_26.png)

![](img/758f53dc6077b8cb2215235a3048b918_27.png)

除了列名和类型之外，DataFrame 还有属性可以告诉我们总行数和总列数。这些信息在数据处理时非常常用，尤其是当我们想要快速判断一个表有多大时，直接用属性读取是最快的办法。下面是几个常用的相关属性：

![](img/758f53dc6077b8cb2215235a3048b918_28.png)

![](img/758f53dc6077b8cb2215235a3048b918_29.png)

![](img/758f53dc6077b8cb2215235a3048b918_30.png)

![](img/758f53dc6077b8cb2215235a3048b918_31.png)

- `height`：返回 DataFrame 的行数，也就是这个表的高度。
- `width`：返回 DataFrame 的总列数，也就是这个表的宽度。
- `shape`：返回一个 Python 元组，同时包含行数和列数。

我可以先访问 `height` 属性，看看 `employees` 这个 DataFrame 里到底有多少行。结果是 1000 行，因为数据集中正好有 1000 名员工：

```python
employees.height
# 1000
```

同时，还有一个互补的 `width` 属性，用来告诉我们列的数量。这里一共有 6 列，所以这个表是 1000 行乘 6 列，总共包含 6000 个值：

![](img/758f53dc6077b8cb2215235a3048b918_33.png)

![](img/758f53dc6077b8cb2215235a3048b918_34.png)

```python
employees.width
# 6
```

![](img/758f53dc6077b8cb2215235a3048b918_35.png)

![](img/758f53dc6077b8cb2215235a3048b918_36.png)

如果你希望一次性拿到这两条信息，那么 `shape` 属性会非常方便。它会返回一个 Python 元组，里面第一个数字是行数，第二个数字是列数，也就是 `(1000, 6)`：

```python
employees.shape
# (1000, 6)
```

当然，如果你后面忘了这些信息具体怎么获取，也不用太担心，因为 Polars 在打印 DataFrame 的时候，本来就会在最顶部自动显示出行数和列数。你只需要直接访问这些已经存在的数据即可。也就是说，你是在向 DataFrame 询问关于它自身的一个问题，而它会直接返回正确的答案，整个过程非常轻松。
