

道德黑客：50天黑客挑战：06：高级枚举：子域名、存活域名与截图 🎯

在本节课中，我们将一起学习高级枚举的完整流程。重点包括如何寻找子域名，如何判断哪些子域名是真正可访问的存活域名，以及如何利用截图工具快速查看大量网站的页面内容。这些内容是后续漏洞扫描阶段的基础，掌握它们可以帮助我们发现隐藏的安全问题和可利用的入口点。



枚举的核心价值

当我们在攻击 Web 应用时，枚举是整个过程的黄金资源，也是发现隐藏文件和隐藏路径的基础。如果我们在前进过程中走不下去了，唯一的办法就是回到枚举阶段，寻找更多的条目或额外的路径，从而继续深入目标系统并寻找漏洞。因此，枚举是渗透测试中至关重要的环节。

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_1.png)

本节课我们会介绍几种工具和自动化方法，这些方法能够帮助我们在想要测试一个组织时，快速定位目标的入口点。这类攻击通常属于非针对性攻击。使用工具可以提高准确性，并在寻找隐藏安全漏洞时发挥作用。常见的工具包括 subfinder、httpx 以及 nucleus 漏洞扫描器等。为了方便讲解，本节课将先限定在前三项核心内容，让你先对整个流程有个直观的认识，因为这些内容是后续漏洞扫描阶段的基础。



第一步：寻找子域名

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_3.png)

以下是关于子域名的基本概念。我们可以把主域名理解为一个组织购买的主站，比如 abc.com。任何出现在主域名前面的部分，都叫作子域名。组织通常会购买一个主域名，然后根据需要创建多个子域名，分别用于管理后台、测试环境、QA 环境或其他非生产网站，有些生产环境的 URL 也可能以子域名形式存在。举个例子，如果我们想要攻击 yahoo.com，那么 yahoo.com 就是主站，任何位于 yahoo.com 之前的部分都是子域名。找出子域名是第一步，也是最关键的一步。

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_5.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_7.png)

在线工具如 c99.nl 提供的子域名查找器可以用来爬取子域名，并且可以标记为私有扫描，声明不会泄露结果。但如果你不想在互联网上留下任何痕迹，更好的方式是使用本地工具。接下来我们将演示的本地工具是 subfinder。如果你不想安装工具，也可以直接使用在线工具，因为在线工具通常已经配置好环境。

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_9.png)

以下是 subfinder 的使用方式。假设目标是 yahoo.com，命令格式如下：

```
subfinder -d yahoo.com -o yahoo_subdomains.txt
```

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_11.png)

这条命令会直接生成输出文件，文件名为 yahoo_subdomains.txt。确保你使用的是最新版本的工具，执行过程需要一些时间。在之前的演示中，这条命令收获了接近 20,400 个子域名。



![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_13.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_14.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_16.png)

第二步：筛选存活域名

找到子域名后，接下来要搞清楚的是，这些子域名中有多少是真正可以访问的网站。所谓存活域名，就是指当前可以正常访问的网站。有些子域名可能指向敏感路径，比如 admin 页面，但该页面可能已经不存在了，这类网站就不属于存活目标。因此，我们需要用工具来筛选出真正的存活目标。

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_18.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_19.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_21.png)

以下是使用 httpx 工具的方法。httpx 是一个专门用于处理 URL 列表的工具包，输入文件就是上一步生成的 yahoo_subdomains.txt。为了方便理解，我在输出结果中加入了一个名为 live 的标注。运行这条命令后，根据 URL 的数量，过程可能需要较长时间。演示中展示的完成结果显示，共有 600 多个子域名被判定为存活网站。

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_23.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_24.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_26.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_27.png)

具体命令示例如下：

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_29.png)

```
cat yahoo_subdomains.txt | httpx -o live.txt
```

在这 2,400 个子域名中，大约有 600 多个被认定为存活网站。



第三步：批量截图与快速查看

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_31.png)

在获得子域名和存活域名信息后，我们还需要了解这些页面的具体情况。比如，我们想知道是否存在管理页面或登录页面，这些页面非常重要，能帮助我们决定是先运行漏洞扫描，还是直接进行利用。不过，手动去查看 600 多个网站的截图是一项非常繁琐且耗时的工作。为了高效获取这些信息，最好的办法是使用工具来生成快照。

以下是我们要使用的 eyewitness 工具。在这 600 多个存活网站中，eyewitness 可以帮我们批量生成截图。命令示例如下：

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_33.png)

```
eyewitness -f live.txt -d yahoo_output --web
```

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_35.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_36.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_37.png)

这条命令会创建一个名为 yahoo_output 的目录，并扫描 80 端口和 443 端口。扫描 600 多个网站的截图需要很长时间，在演示中大约花费了两个小时。工具运行过程中会以一定间隔提示进度，例如显示已完成 150 个，或者已完成 420 个，直到所有目标扫描完毕。扫描完成后，工具会提示所有端点已处理完毕，结果保存在 yahoo_output 文件夹中。你可以直接进入该文件夹查看，也可以选择直接打开报告页面。



第四步：解读扫描结果

工具生成的报告包含大约 26 个页面，主要页面是 report.html。进入报告后，你可以看到分层概览。以第一个网站为例，页面显示加载中，说明截图耗时较长。你也可以通过访问对应 URL 来验证结果。往下查看，报告中会列出其余 URL 的快照，这样我们就能快速了解每个页面的着陆情况。

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_39.png)

这种方式能帮助我们在两分钟内完成高层面的概览，而手动方式则非常耗时。在浏览过程中，你会看到一些关键信息，比如 403 禁止访问页面，这通常意味着页面被隐藏，很可能包含敏感信息。另外，还会出现 500 错误、400 错误，以及加载时间较长的页面。通过这些截图，我们可以快速统计有多少个 200 响应，多少个 400 响应，多少个 403 有趣的页面，以及有多少个错误页面，从而判断是否存在管理页面或其他入口点，决定是否要进一步探测。



![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_41.png)

第五步：进阶自动化与漏洞扫描

除了上述步骤，还有两项可选的进阶内容。第一项是使用方式归档工具，在线或基于浏览器的方式都可以，用来寻找特定存活子域名的入口点和敏感信息。你可以将 live 子域名文件通过管道符传给 wayback URL 工具，生成 wayback_urls.txt 文件，从而帮助发现更多入口点。

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_43.png)

第二项是使用 nucleus 漏洞扫描器对存活站点进行扫描。如果你想运行特定模板，例如针对 SMB 的开放看板模板，或者针对特定应用的模板，可以将 nucleus 的扫描结果作为输出。所有这些工具都可以通过管道符连接，像下面这样实现自动化：

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_45.png)

```
subfinder -d yahoo.com | httpx | eyewitness
```

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_46.png)

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_48.png)

使用管道符可以将原本逐步完成的流程自动化起来。对于 yahoo.com 来说，整个枚举过程大约花费了 3 到 4 小时。如果在 600 个存活子域名上再运行 nucleus，大约能发现 70 个问题。如果逐个域名单独运行 70 次扫描，耗时会更长。因此，高级枚举在渗透测试、红队演练或漏洞奖励计划中非常实用，能够帮助我们以便捷的方式发现隐藏的安全漏洞。



本节课总结

![](img/43fa35d7a6ccdda5f9fabd922af2e8c6_50.png)

在本节课中，我们一起学习了高级枚举的完整流程，包括寻找子域名、筛选存活域名、批量截图与快速查看、解读扫描结果，以及通过管道符实现自动化进阶。掌握这些方法后，你可以在几个小时内完成对一个域名的枚举工作，并快速定位有价值的攻击入口点。希望你喜欢这次演示，我们下次演示再见。
