

# Polars与Python数据分析：44：没有索引也没问题 📊

在本节课中我们将要学习Polars中与索引相关的内容。课程会先回顾pandas里的索引概念，再说明Polars数据框默认没有索引，然后学习`with_row_index`方法以及它的`offset`和`name`参数，最后学习在读取CSV文件时通过`read_csv`的`row_index_name`和`row_index_offset`参数直接添加索引。整个教程会用大白话解释，让初学者也能看懂每一步在做什么，以及这些操作为什么有用。

## Polars与Python数据分析：44.1：先认识pandas的索引 🧭

上一节我们导入了员工数据框，本节中我们来看看索引的基本概念。如果你以前用过pandas库，应该对索引不陌生。索引是数据框左侧的一串递增数值序列，它充当数据集中每一行唯一标识的集合。pandas里的标准数值索引会先把第一行分配为位置0，再把第二行分配为位置1，一直分配到数据框末尾。这个思路和Python列表的索引位置非常相似，列表中的每个元素也同样按顺序获得一个数字编号，这个编号就是索引位置，并且从0开始。

\[
index_i = i,\quad i=0,1,2,\dots
\]

上面这个公式表示默认情况下第`i`行的索引值就是`i`，其中`i`从0开始计数。为了更直观地理解，可以看下面这段Python列表代码，列表第一个元素的索引位置是0，第二个元素的索引位置是1，和数据框默认索引的计数方式一致。

```python
["a", "b", "c"][0]  # "a"
["a", "b", "c"][1]  # "b"
```

理解了pandas的索引之后，下面进入Polars的世界。Polars对索引的处理思路和pandas不一样，它默认不会给数据框附加一列索引，因此需要掌握专门的方法来创建等价物。

## Polars与Python数据分析：44.2：Polars默认没有索引 🐻

上一节我们介绍了pandas索引从0开始编号的方式，本节中我们来看看Polars的默认行为。Polars中的数据框默认没有任何形式的索引，这一点和pandas不同。不过Polars提供了一个方便的方法叫`with_row_index`，可以用它来创建行索引。为了演示，先重新执行上一节课的代码，导入员工数据框，代码如下。

```python
import polars as pl

employees = pl.read_csv("employees.csv")
```

接着对员工数据框调用`with_row_index`方法，代码如下。调用后Polars会自动在数据框里创建一列新列，你可以看到它出现在左侧，列名默认叫`index`。

```python
employees.with_row_index()
```

这个默认索引列的类型是无符号32位整数，也就是`UInt32`，原因是索引值不可能为负数，只能取0和正整数。你还可以看到索引从0开始，然后给每一行按顺序分配一个数字编号，形成整齐的行号序列。用集合的方式描述就是`index_i ∈ {0,1,2,...}`，其中每个值对应一行的位置。默认索引从0开始很方便，但有些场景希望起点不是0，下一节就来看控制起点的参数。

## Polars与Python数据分析：44.3：用offset控制索引起点 ⚙️

上一节我们看到默认索引从0开始，本节中我们来看看如何改变索引的起始值。如果你不想要从0开始的索引，`with_row_index`里有一个参数叫`offset`，它用来设置索引的起始值，也就是从哪个数字开始计数。这个参数的默认值是0，对应上面已经看到的结果。如果给`offset`传入1，再调用`head`方法预览前五行，就会得到左侧同样的索引列，但计数从1开始，每一行都有一个数字标识，几乎就像行号一样。

```python
employees.with_row_index(offset=1).head()
```

此时索引的生成规则可以写成下面的公式，其中`offset`是起点，`i`仍然表示行位置并从0开始。

\[
index_i = offset + i
\]

如果希望使用任意数值作为起点，也可以传入类似58这样的值。例如你有一批数据，其中一些数据丢失了，想表示Nicholas Maldonado是公司第58位入职的员工，就可以把索引起点设为58。索引起点可以是任何你需要的数值，下面列出`offset`参数在本节中的几个用法。

- 默认`offset=0`：索引从0开始，对应默认行为。
- `offset=1`：第一行索引从1开始，适合把索引当作行号使用。
- `offset=58`：第一行索引从58开始，可表达业务上的第58位员工等含义。

这些用法都通过`with_row_index`完成，起点改变后索引仍然是一列整齐的数值标识。除了起点，索引列的名称也可以自定义，下一节就来看`name`参数。

## Polars与Python数据分析：44.4：自定义索引列名 🏷️

上一节我们通过`offset`控制了索引从哪个数字开始，本节中我们来看看如何修改索引列的名称。如果不想让索引列使用默认名称`index`，可以使用`name`参数。这个参数接收一个字符串，用来指定索引列名。例如把`name`设为字符串`"I"`，同时把`offset`设为58，就会得到第一行索引从58开始、列名为`I`的索引列。代码如下。

```python
employees.with_row_index(name="I", offset=58).head()
```

这些操作都包含在`with_row_index`方法内部，`name`负责列名，`offset`负责起点，二者可以组合使用。到这里，我们已经可以在已有数据框上灵活添加索引列。接下来换一个场景，看看在导入CSV文件时能不能直接附加索引。

## Polars与Python数据分析：44.5：在读取CSV时直接添加索引 📥

上一节我们在已有数据框上添加索引，本节中我们来看看在导入阶段直接添加数值索引的方法。除了`with_row_index`，还可以在导入时分配数值索引，具体做法是自定义`read_csv`函数的参数，让Polars自动附加索引列。再次使用Polars库的`read_csv`函数，并把员工CSV文件传进去，会发现有一个参数叫`row_index_name`。这个参数默认值是`None`，表示不创建行索引；如果给它一个名称，Polars就会自动把索引列附加到左侧。例如把名称设为`ID`，就能看到左侧生成一列`ID`，并且默认从0开始。

```python
employees = pl.read_csv("employees.csv", row_index_name="ID")
```

另外一个相关参数叫`row_index_offset`，它用来设置起始数字，也就是起始索引位置。如果希望计数从1开始而不是默认的0，就可以给这个参数传入1，于是左侧的`ID`列会作为索引列，并从1开始计数。下面列出`read_csv`里与索引直接相关的两个参数。

- `row_index_name`：默认`None`，不创建行索引；给它名称后自动在左侧附加索引列。
- `row_index_offset`：设置索引起始数字，例如传1就从1开始计数。

把两个参数组合起来，就可以在读取CSV时直接生成带自定义列名和自定义起点的索引列。代码如下。

```python
employees = pl.read_csv(
    "employees.csv",
    row_index_name="ID",
    row_index_offset=1,
)
```

以上就是在导入阶段添加索引的方法，也是把pandas索引的等价物添加到Polars数据框中的完整做法。下面进入本节总结，把前面的知识点串起来。

## Polars与Python数据分析：44.6：本节总结 🧾

本节课中我们一起学习了Polars中与索引相关的核心内容。我们先用pandas的索引作为参照，理解了索引是数据框左侧的递增数值序列，也是每一行唯一标识的集合，默认从0开始编号，和Python列表的索引位置思路相似。随后我们看到Polars数据框默认没有索引，但可以通过`with_row_index`方法创建索引列，默认列名是`index`，类型是无符号32位整数，默认从0开始。接着我们学习了`offset`参数，它可以把索引起点改成1、58或其他任意数值，还学习了`name`参数，它可以把索引列名改成自定义字符串。最后我们学习了在`read_csv`导入阶段直接添加索引的方法，其中`row_index_name`负责索引列名，默认`None`表示不创建索引，`row_index_offset`负责索引起点。掌握这些内容后，就可以根据需要在Polars中灵活添加与pandas索引等价的索引列了。
