
# Adobe Lightroom 照片编辑从入门到精通大课：55：从社区保存预设 📸

![](img/fb95bbb54404eb8d6620b9e44fa53452_0.png)

![](img/fb95bbb54404eb8d6620b9e44fa53452_2.png)

在本节课中，我们将学习如何从其他创作者那里下载或保存预设，并把这些预设应用到自己的照片上。我们还会看到如何根据自己的需求对预设进行微调，最后把调整好的结果保存为个人预设，甚至分享到 Lightroom 社区里。

有时候我们拍摄了一张照片，却觉得手头现有的预设都不太合适，这时候就可以去 Lightroom 社区看看其他人是怎么编辑图片的。社区里的作品可以提供很多拍摄和后期的参考方向，让你找到新的创作灵感。

以下是寻找社区预设的方法：

- 打开 Lightroom 社区，浏览其他创作者分享的照片。
- 如果你编辑的是建筑照片，可以进入建筑分类，了解新的编辑思路。
- 当你发现一张灯光和色彩与自己照片比较相似的图片时，就可以把它的预设保存下来。
- 保存后，该预设就会出现在你的预设列表里，方便以后直接套用。

![](img/fb95bbb54404eb8d6620b9e44fa53452_4.png)

![](img/fb95bbb54404eb8d6620b9e44fa53452_6.png)

接下来，我们来看看如何把社区里的预设保存到自己的账号中。在社区浏览时，每张照片左上角都会显示创作者的名字，这能帮你确认预设的来源。点击进入编辑详情页之后，你可以一步步查看对方是如何处理这张图片的。

你会看到对方到底做了哪些调整，比如裁剪、提亮高光，以及其他面板上的操作。甚至可以知道原始图片是 JPEG 还是 PNG 格式。页面底部会提供一个选项，允许你将这张图片的编辑步骤保存为预设。点击保存之后，预设就会被添加到你的“使用的预设”里面。

预设的保存逻辑可以用下面的代码简单表达：

![](img/fb95bbb54404eb8d6620b9e44fa53452_8.png)

```
保存的预设 = 原创作者的全部编辑步骤
```

保存完预设之后，我们需要在自己的图片上实际测试一下效果。因为别人预设在他们的照片上看起来很好，并不意味着套用到你的照片上也会同样好用。所以最好准备几个备用预设，以防第一个效果不理想。

![](img/fb95bbb54404eb8d6620b9e44fa53452_10.png)

![](img/fb95bbb54404eb8d6620b9e44fa53452_11.png)

以下是测试预设的步骤：

- 回到你的图库，选择刚才编辑过的那张照片。
- 确保你选择的预设分类与照片内容匹配，比如建筑照片就选建筑分类，这样曝光和色调才会更准确。
- 如果分类选错了，比如把网球照片放进建筑分类，就会让浏览者感到困惑。
- 在开发模块中依次套用保存的预设，观察哪一个在你的照片上表现更好。

接下来是对预设进行个人调整。套用他人预设后，照片可能还是太亮、颜色过饱和，或者色调不合适。这时候我们可以根据自己的喜好进一步修改。

以下是常见的调整项：

![](img/fb95bbb54404eb8d6620b9e44fa53452_13.png)

- 高光：拉低高光，挽回过曝部分的细节。
- 白色：适当调整白色，让画面亮度更自然。
- 饱和度：如果蓝色过于艳丽，可以把饱和度调低。
- 绿色：调整绿色色相，让植物或环境颜色更协调。
- 校正：如果照片是倾斜的，可以手动拉直，也可以让 Lightroom 自动校正。
- 去雾：略微降低去雾数值，增加对比度，保留画面细节。
- 配置文件：在配置文件里选择艺术类预设，比如艺术三号，如果喜欢可以点击星号加入收藏。

![](img/fb95bbb54404eb8d6620b9e44fa53452_15.png)

处理完这些参数后，你会发现照片已经变得更符合自己的审美了。这时候你是在别人预设的基础上，加上了自己的调整。

个人预设的构成可以用下面的代码表示：

![](img/fb95bbb54404eb8d6620b9e44fa53452_17.png)

![](img/fb95bbb54404eb8d6620b9e44fa53452_18.png)

```
个人预设 = 原创作者预设 + 我的高光、白色、饱和度、校正等调整
```

![](img/fb95bbb54404eb8d6620b9e44fa53452_20.png)

![](img/fb95bbb54404eb8d6620b9e44fa53452_22.png)

调整满意之后，我们可以把这个新版本保存为个人预设。再次进入右侧工具栏，找到下方像图表一样的图标，进入“已保存预设”界面。

![](img/fb95bbb54404eb8d6620b9e44fa53452_24.png)

保存自己的预设需要按以下步骤操作：

![](img/fb95bbb54404eb8d6620b9e44fa53452_26.png)

- 先点击右下角的对勾图标确认当前调整。
- 点击三个点图标，选择“用当前设置更新”。
- 再次点击对勾图标完成保存。
- 这样，你的个人预设就同时包含了原创作者的设置和你自己的修改。
- 这个操作不会改变原创作者最初发布的预设，只会更新你本地保存的那个副本。

![](img/fb95bbb54404eb8d6620b9e44fa53452_28.png)

![](img/fb95bbb54404eb8d6620b9e44fa53452_30.png)

保存完个人预设之后，我们可以尝试在另一张照片上验证效果。这次我们找一张夜景照片，比如夜间拍摄的城市建筑。因为夜景和白天照片的光线完全不同，所以之前的预设可能需要重新微调。

以下是在夜景照片上使用预设的方法：

![](img/fb95bbb54404eb8d6620b9e44fa53452_32.png)

![](img/fb95bbb54404eb8d6620b9e44fa53452_33.png)

- 回到社区，寻找夜景类别的图片，避免选择包含大量星空的照片，因为你的照片里没有星星。
- 选中一张灯光效果接近的建筑夜景，保存它的预设。
- 回到图库，找到你的夜景照片，进入预设面板。
- 选择刚才保存的“城市灯光”预设，看看效果是否合适。
- 如果照片太暗，可以提高曝光度，适当提升黑色阶，因为夜间场景很难拍出太多灯光细节。
- 如果需要，可以给画面增加暖色调，突出多彩的天空，或者保持冷色调营造神秘氛围。
- 最后可以加一点锐化，减少噪点，让图像更清晰。

夜景曝光的修正思路可以用下面的代码表示：

![](img/fb95bbb54404eb8d6620b9e44fa53452_35.png)

![](img/fb95bbb54404eb8d6620b9e44fa53452_37.png)

```
夜景曝光修正 = 原始曝光 + 提高曝光度 + 适当提升黑色阶
```

![](img/fb95bbb54404eb8d6620b9e44fa53452_39.png)

调整好夜景照片之后，如果你想把自己的成果分享出去，可以将作品发布到 Lightroom 社区的个人作品集中。

![](img/fb95bbb54404eb8d6620b9e44fa53452_41.png)

分享作品需要注意以下几点：

- 点击“导出为”上方的分享图标，选择“分享编辑”。
- 给作品起一个标题，比如“三角屋顶”或“夜景城市”，名称随意即可。
- 选择与照片内容相关的分类，比如先选“夜景”，再选“建筑”，如果画面里有旅行元素也可以加上“旅行”。
- 不要随便选分类，否则会干扰社区，让寻找夜景摄影的人看到无关的早晨照片，浪费他们的时间。
- 开启“允许他人保存你的预设”选项，这样其他人就可以使用你的预设，增加你的曝光率。
- 如果愿意，可以开启位置信息，让别人知道拍摄地点和时间。
- 版权信息保持默认即可，最后点击完成，等待作品提交上线。

![](img/fb95bbb54404eb8d6620b9e44fa53452_43.png)
