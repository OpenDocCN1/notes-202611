
# CompTIA Linux+ V8：第25章：列出硬件设备 🖥️

在本节课中，我们将学习如何在 Linux 系统中列出硬件设备。你将认识一组实用的命令行工具，这些工具能够帮助你查询 CPU、内存、USB、PCI 以及块设备等硬件信息。无论你是排查硬件问题，还是仅仅想了解系统当前的配置，这些命令都是必备的基础技能。本节内容适合初学者，会用大白话把每个命令的作用讲清楚，让你轻松上手。


## 25.1 Linux 中常见的硬件列举命令

Linux 发行版自带多个命令，用于列出当前系统中的硬件设备。每个 Linux 发行版都自带不少用于列出硬件设备的命令，例如 lshw。它能显示当前所有硬件的概览。lscpu 命令列出 CPU 及其属性。或者 lsblk 用于列出块设备。lspci 显示 PCI 总线上的设备。lsusb 列出 USB 设备。还有 lsmem，它列出内存设备。最后是 lsinitrd，它显示 initrd 文件中的内容。

这些命令各有侧重，有的显示全部硬件概览，有的则专门针对某一种设备类型。下面是几个最常用的命令及其用途：

- `lshw`：显示所有当前硬件的概览信息。
- `lscpu`：列出 CPU 及其属性。
- `lsblk`：列出块设备。
- `lspci`：显示 PCI 总线上的设备。
- `lsusb`：列出 USB 设备。
- `lsmem`：列出内存设备。
- `lsinitrd`：显示 initrd 文件中的内容。

以上命令可以帮助你快速了解系统里装了什么硬件，建议先整体印象，再针对具体需求深入查看。


## 25.2 使用 lshw 查看完整硬件信息

如果你想一次性查看系统中所有硬件的详细信息，`lshw` 是最全面的选择。让我来演示这些工具。但请注意，并非所有工具在所有发行版中默认都安装。让我们看看能做到哪一步。我一开始想用 sudo -i，不过先别这么做了，我们直接用 lshw 吧。

你看到的信息量很大，而且它提示你应该以超级用户身份运行此程序，也就是说要用 sudo lshw，并且我将输出通过管道传给 less，因为信息无法在一屏显示完。核心操作命令如下：

```bash
sudo lshw | less
```

运行后你会看到非常详细的硬件清单，这里有系统中所有硬件的非常详细的信息，包括内存插槽中的内存银行等，应有尽有。我再说一遍，信息量非常大，以至于有点复杂，因此如果你在找特定内容，最好使用更专门的命令，而不是直接使用 `lshw`。


## 25.3 查看 CPU 信息：lscpu

上一节我们介绍了如何用 `lshw` 查看整体硬件概览，本节中我们来看看如何专门查看 CPU 信息。

`lscpu` 命令用于显示处理器的详细属性。比如 lscpu，它显示关于我的 CPU 的信息，它合并了 /proc/cpuinfo 中的信息与其他发现的信息，尽可能完整地展示你的 CPU 状况。你看这里它找到了 Apple Silicon，这是因为即使我在虚拟化中，它也直接寻址我的 Apple Silicon CPU，它发现了两个 CPU，我们还能获取更多信息，例如正在使用的缓存等等。

使用方式非常简单：

```bash
lscpu
```

这条命令不需要特殊权限，直接运行即可得到关于 CPU 的完整报告。


## 25.4 查看块设备：lsblk

刚才我们学习了如何查看 CPU 信息，本节中我们来看看如何列出块设备。

现在 lsblk 列出块设备，我们已经见过它了，lsblk 对于管理可移动设备和硬盘都很方便。块设备包括硬盘、固态硬盘、U 盘等可读写的存储设备。`lsblk` 命令专门用于列出这些设备，它会以树状结构展示设备名称、大小、挂载点等信息，帮助你确认系统识别到了哪些存储设备。

```bash
lsblk
```

执行后你会看到当前系统中所有块设备的清单，便于后续进行分区、挂载或故障排查。


## 25.5 查看 PCI 设备：lspci

在了解了块设备之后，本节中我们来看看如何查看 PCI 总线上的设备。

lspci 列出 PCI 总线，你可以直接输入 lspci 查看简短列表，但通常目的是找出加载了哪些内核模块，这里可以看到所有可用的不同内核模块。PCI 总线连接着显卡、网卡、声卡等多种扩展卡。`lspci` 命令用于显示 PCI 总线上的设备列表。这对确定硬件是否被正确识别非常有帮助。

```bash
lspci
```

通过该命令，你可以一览系统中所有 PCI 设备及其对应的内核模块信息。


## 25.6 查看 USB 设备：lsusb

上一节我们介绍了 PCI 设备的查看方法，本节中我们来看看 USB 总线上的设备。

我们已经见过 lsusb，用于列出 USB 总线上的情况。`lsusb` 命令用于列出当前连接到 USB 总线的设备，例如键盘、鼠标、U 盘、摄像头等。它能帮助你确认外设是否已被系统识别，是排查 USB 设备无法使用问题的常用工具。

```bash
lsusb
```

运行后会列出所有 USB 设备的厂商 ID、产品 ID 以及设备名称等信息。


## 25.7 查看内存配置：lsmem

刚才我们学习了 USB 设备的查看方法，本节中我们来看看如何查看内存配置。

不太常见的是 lsmem，lsmem 显示你的内存配置。`lsmem` 命令用于显示系统的内存设备及配置信息。在普通系统上，内存配置并不特别。但如果你使用非统一内存访问或 NUMA，那么 lsmem 会提供关于你内存拓扑的有趣信息。

```bash
lsmem
```

这条命令适合需要关注内存物理布局的高级场景，日常使用中可以简单了解即可。


## 25.8 查看 initrd 内容：lsinitrd

在介绍了内存配置之后，本节中我们来看看如何查看 initrd 文件的内容。

最后 lsinitrd 显示 initrd 中的情况。记住 initrd 文件是一个文件系统，帮助内核正常启动。`lsinitrd` 命令用于显示 initrd 文件中包含的内容。initrd 是一个完整的文件系统，包含目录结构，也包含驱动程序。如果你需要弄清楚哪些驱动可用，看这里，它们在列表顶部。这可能帮助你判断是否需要向 initrd 安装额外驱动。

```bash
lsinitrd
```

通过这个命令，你可以直接查看引导过程中使用的驱动和文件，辅助排查启动相关问题。
