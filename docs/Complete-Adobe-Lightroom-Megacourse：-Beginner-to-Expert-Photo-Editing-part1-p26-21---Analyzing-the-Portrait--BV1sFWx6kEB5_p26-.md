# 📸 Adobe Lightroom 零基础到专家照片编辑完整大课：第21课：分析人像


![](img/883aae19fb06bbd52e5379355d509659_1.png)

在本节课中，我们将要学习如何在开始编辑之前，先仔细分析一张人像照片到底需要改进哪些地方。很多刚接触 Lightroom 的新手，打开软件后就直接拖动滑块，结果往往漏掉最重要的问题，或者调了半天发现方向错了。所以在这一课里，我们不急着动参数，而是先学会像专业摄影师一样观察照片，心里有个清晰的修图计划。这样不仅能让后期工作更有条理，还能避免很多不必要的返工，让你的照片效果更好。


在开始编辑任何照片之前，第一件事就是看清楚这张图片到底需要什么。不要一打开 Lightroom 就直接动滑块，先花一点时间观察光线、颜色和主体，心里要有个大概的计划。只有先分析清楚，后面调整参数的时候才不会盲目，也不会因为顺序错了而导致效果反复。


以下是本节课的核心练习任务：

- 把本节课提供的人像照片，使用我们目前学过的所有知识点，进行一次完整的改造。
- 仔细观察照片里各个需要修复的元素，并决定先处理哪一个，再处理下一个。


大家可能已经知道，后期调色几乎总是从光线开始，因为光线决定了照片里颜色的表现力和细节的多少。如果整体光线不够，后面再调多漂亮的颜色也看不出效果，所以光线永远是第一步。


光线调整的具体要点如下：

- 把整体亮度适当提高，让照片看起来更明亮一些。
- 把背景里的一些颜色也带出来，避免背景显得太暗或太死。


光线大致调好之后，接下来要关注背景里的干扰元素。在这张人像照片里，背景有一些树叶，它们的颜色太鲜艳了，容易抢走观众对主体的注意力，让人看过去先看树叶而不是看人。


背景树叶的处理建议如下：

- 尝试改变树叶的色相，让颜色不那么突兀。
- 或者降低树叶的亮度，让它们变暗一点，不再抢镜。


背景不过分抢眼之后，我们就可以把注意力集中到拍摄对象身上了。这张人像的人物脸部细节比较丰富，我们需要仔细看看可以怎么增强，让主体更出彩。


人物脸部修饰的思路如下：

- 你可以看到模特脸上有雀斑，可以使用蒙版工具让这些雀斑更显眼，或者根据自己的喜好保持自然。
- 可以把模特本来就有的自然肤色带出来，让皮肤看起来更健康、更有质感。
- 如果你喜欢，还可以添加一点色彩分级，让画面偏暖一些；如果你喜欢冷色调，保持偏冷也完全没问题，这全凭你个人的喜好。


核心的编辑优先级可以用下面这个简单公式来概括：

**编辑优先级公式**：`光线调整 → 背景处理 → 人物细节 → 色彩分级`

或者用代码块表示执行顺序：

```
第一步：整体光线调整
第二步：背景元素处理
第三步：人物面部细节修饰
第四步：根据喜好添加色彩分级
```


不管具体怎么调整，最重要的原则永远是：先分析图像，再动手编辑；先处理光线，再一步步往后进行，按照我们之前学过的顺序来。不要跳步骤，也不要乱序调整，这样修出来的照片才会更统一、更专业。


以下是建议你随身带的检查清单：

- 第一步：整体光线调整。
- 第二步：背景元素处理。
- 第三步：人物面部细节修饰。
- 第四步：根据喜好添加色彩分级。


请拿出一张纸和一支笔，把需要做的步骤写成清单放在身边，因为本章接下来的三节课里，我们会一起在这张照片上进行实操练习。

本节课中，我们一起学习了如何在编辑前分析人像照片，掌握了从光线到背景再到人物细节的处理顺序，并且知道了如何制作简单的编辑检查清单。希望你在下节课动手之前，先花几分钟把照片里的问题列出来，这样修图会更高效，效果也会更好。
